## 新产品
1. **Peras: a weekly usage line for Claude Code and Codex**: set something like `peras set weekly 85 pause`, and once your weekly usage crosses that line the agent's next tool call is refused with a plain reason, so one long task can't burn the rest of your week; resume any time from the terminal or the menu bar. It reads `rate_limits.seven_day.used_percentage` from Claude Code's status-line input rather than estimating from tokens. CLI and hooks are free and MIT, the native Mac menu bar app is €4.99 once; macOS only for now, and `claude -p` can't be stopped. https://peras.vertias.eu [Product Hunt](https://www.producthunt.com/products/peras)
> [zh] **Peras：给 Claude Code 和 Codex 的每周额度划一条线**：比如设 `peras set weekly 85 pause`，每周用量超过这条线后，agent 的下一次工具调用会被拒绝并给出原因，免得一个长任务把整周额度烧光；随时可以在终端或菜单栏恢复。它读的是 Claude Code 状态栏输入里的 `rate_limits.seven_day.used_percentage`，不是按 token 估算。CLI 和 hooks 免费、MIT 协议，原生 Mac 菜单栏应用一次性 4.99 欧元；目前只支持 macOS，`claude -p` 拦不住。
2. **Pristine: an agent skill that critiques and polishes web UI**: it looks at the real page in light and dark, desktop and mobile, judges it through your users' personas, then either scores it out of 10 across 11 dimensions or fixes it. Commands are `/pristine init` (writes a DESIGN.md), `critique`, `design` and `polish` with 16 lenses such as bolder, typeset or quieter. Works with Claude Code, Codex, Copilot, Cursor and any agent that reads SKILL.md; Apache 2.0, posted as a Show HN today. https://pristine-ui.pages.dev [GitHub](https://github.com/maddhruv/pristine) ｜ [HN](https://news.ycombinator.com/item?id=50204389)
> [zh] **Pristine：帮 agent 评审和打磨网页 UI 的技能**：它会实际打开页面，看亮色、暗色、桌面和手机四种状态，按你产品用户的画像来评判，然后要么从 11 个维度打 10 分制的分，要么直接改。命令有 `/pristine init`（生成 DESIGN.md）、`critique`、`design`，以及带 16 种侧重（如 bolder、typeset、quieter）的 `polish`。支持 Claude Code、Codex、Copilot、Cursor 和任何能读 SKILL.md 的 agent；Apache 2.0，今天发在 Show HN。
3. **Agent Hunt: a live leaderboard of the tools AI agents actually call**: Monid, which bills itself as "OpenRouter for agent tools" and connects agents to 2,700+ APIs with 0% markup, now publishes daily rankings of the most-used tools, most-called endpoints and fastest-growing tools, all based on real calls agents make through its gateway. #4 on Product Hunt today; commenters say the endpoint view is the useful part, though usage isn't the same as usefulness. https://monid.ai/rankings [Product Hunt](https://www.producthunt.com/products/monid)
> [zh] **Agent Hunt：AI agent 真实调用最多的工具实时榜**：自称「agent 工具界的 OpenRouter」、以零加价帮 agent 接入 2700 多个 API 的 Monid，现在每天按 agent 经它网关产生的真实调用，公布用得最多的工具、调用最多的接口和增长最快的工具三张榜。今天 Product Hunt 第 4；评论认为按接口看最有用，不过用得多不等于好用。
4. **The Enron Brain: an AI-written company wiki where every fact cites an email**: this+that fed 45,047 Enron emails to an AI, which wrote 214 pages on the companies, regulators and banks Enron dealt with, 49,401 facts in total, each citing its source email, with a time slider that expires facts once the mail shows they stopped being true. A held-out audit by a second AI found 93% of sampled facts fully supported and 0 of 500 wrong at their core. A good reference for anyone building agent memory or knowledge bases with provenance. https://www.thisandthat.chat/enron/ [HN](https://news.ycombinator.com/item?id=50207620)
> [zh] **Enron Brain：每条事实都引用原始邮件的 AI 公司百科**：this+that 把 45047 封安然邮件交给 AI，自动写出 214 页关于安然往来公司、监管机构和银行的条目，共 49401 条事实，每条都注明出自哪封邮件；拖动时间滑块，邮件显示已失效的事实会按日期过期。用另一个 AI 做的留出审计显示，抽样事实 93% 完全有据，500 条里核心错误为 0。给 agent 做带出处的记忆或知识库，可以参考它的做法。
5. **Instant Search: local semantic file search for Mac**: it uses a bidirectional late-interaction embedding model (from Perplexity, per the maker) instead of one vector per document, so you can type "driver's license" or describe a note's context and get the exact file and page; the maker claims a 95% hit rate and under 1 GB of index for an average library. Free, #12 on Product Hunt today. https://useinstantsearch.com [Product Hunt](https://www.producthunt.com/products/instant-search-2)
> [zh] **Instant Search：Mac 上的本地语义文件搜索**：它用双向 late-interaction 嵌入模型（作者说来自 Perplexity），而不是给每篇文档只存一个向量，所以输入「驾照」或描述一下笔记的上下文，就能找到具体的文件和页码；作者称命中率 95%，一般资料库的索引不到 1GB。免费，今天 Product Hunt 第 12。

## 科技新闻
1. **OpenCode: a malicious MCP server could run code on Windows/WSL during sign-in**: OpenCode passed the server-supplied OAuth authorization endpoint unescaped to an old version of the `open` package, so a malicious or later-hijacked remote MCP server could run PowerShell when you started its sign-in. Versions 1.0.137–1.18.32 on Windows and WSL are affected (macOS and Linux are not); Pillar Security rates it 9.8. It was quietly fixed in 1.18.33 on Sep 28 with no CVE or advisory, so scanners won't flag it: upgrade, run `opencode mcp list` and remove remote MCP servers you haven't vetted. https://pwn.watch/i/opencode-mcp-oauth-rce-windows
> [zh] **OpenCode：恶意 MCP 服务器能在你登录时在 Windows/WSL 上执行代码**：OpenCode 把 MCP 服务器给的 OAuth 授权地址不加转义地交给旧版 `open` 包，于是恶意或后来被劫持的远程 MCP 服务器，能在你发起登录时执行 PowerShell。受影响的是 Windows 和 WSL 上的 1.0.137–1.18.32（macOS、Linux 不受影响），Pillar Security 评 9.8 分。官方 9 月 28 日在 1.18.33 里悄悄修了，没有 CVE 也没有公告，扫描器不会报：赶紧升级，跑一下 `opencode mcp list`，删掉没审过的远程 MCP 服务器。
2. **x402 agent-payment SDKs had three critical flaws, and npm audit won't tell you**: V12 disclosed 25 issues; the critical ones were no default spending limit in the client (a hostile API could ask for an agent's whole token balance), the TypeScript Solana facilitator accepting token approvals as payments, and the SIWx helper signing login messages for other sites. All were fixed in the Aug 18 releases without an advisory; update `@x402/fetch`, `@x402/axios`, `@x402/extensions` and `@x402/svm` to 2.23.0+. Patched clients now cap each payment at $1 by default. https://pwn.watch/i/x402-sdk-critical-flaws-v12
> [zh] **x402 agent 支付 SDK 有三个严重漏洞，npm audit 却不会提醒**：V12 披露了 25 个问题，严重的三个是：客户端默认没有消费上限（恶意 API 可以直接要走 agent 的全部代币余额）、TypeScript 版 Solana facilitator 把代币授权当成付款、SIWx 登录助手会替其他网站签登录消息。8 月 18 日的版本都已修复但没发公告；把 `@x402/fetch`、`@x402/axios`、`@x402/extensions`、`@x402/svm` 升到 2.23.0 以上。修复后的客户端默认单笔最多付 1 美元。
3. **pgrust was caught gaming ClickBench, and is back with a new submission**: the merged removal PR by ClickHouse's Alexey Milovidov showed the Rust Postgres reimplementation shipped hand-written kernels for individual benchmark queries, compiled the benchmark SQL into the executor, and served hot runs from cached answers: Q20 took 10.8 s cold and 5 ms on the third run. A new v0.4-beta entry opened Oct 22 with public source and every cache listed with its setting. HN commenters wonder whether this is AI "cheating" in an eyes-free vibe-coded project. https://github.com/ClickHouse/ClickBench/pull/2165 [New submission](https://github.com/ClickHouse/ClickBench/pull/2751) ｜ [HN](https://news.ycombinator.com/item?id=50205816)
> [zh] **pgrust 被扒出在 ClickBench 刷榜，现在又重新提交**：ClickHouse 的 Alexey Milovidov 提的移除 PR（已合并）显示，这个用 Rust 重写的 Postgres 针对单条基准查询手写了专用内核，把基准 SQL 直接编进执行器，热跑时直接回放缓存结果：Q20 冷跑 10.8 秒，第三次只要 5 毫秒。10 月 22 日它又提交了 v0.4-beta，这次公开源码并逐项列出缓存及开关。HN 评论在讨论这是不是「不看代码的 vibe coding 项目里 AI 在作弊」。
4. **Swedish government offices to block ChatGPT and Claude**: per Sveriges Radio, the Government Offices will block the two services because they want staff to use approved tools, including Microsoft Copilot. HN commenters read it as a Copilot lock-in rather than a data-sovereignty move, since Copilot is also a US vendor. https://www.sverigesradio.se/artikel/chat-gpt-och-claude-forbjuder-regeringskansliet [HN](https://news.ycombinator.com/item?id=50207405)
> [zh] **瑞典政府办公室将屏蔽 ChatGPT 和 Claude**：据瑞典广播电台报道，政府办公室要屏蔽这两个服务，理由是希望员工使用经批准的工具，其中包括微软 Copilot。HN 评论认为这更像是绑定 Copilot，而不是数据主权考虑，因为 Copilot 同样是美国厂商。
5. **The same AI request emits 8.5x more CO₂ in Texas than in Sweden**: Swedish provider Berget AI, with the Stockholm Environment Institute, WattTime and Klimatkollen, open-sourced a per-request carbon method that includes hardware manufacturing. A typical Kimi K3 request on identical hardware emits about 0.4 g in Sweden, 1.6 g in Ireland, 2.5 g in Germany and 3.2 g in Texas. HN debated whether location-based accounting means much, and noted reasoning effort can swing token use by two orders of magnitude. https://berget.ai/en/blog/per-request-co2-press-release [HN](https://news.ycombinator.com/item?id=50205229)
> [zh] **同一个 AI 请求，在德州的碳排放是瑞典的 8.5 倍**：瑞典 AI 服务商 Berget AI 联合斯德哥尔摩环境研究所、WattTime 和 Klimatkollen，开源了一套按请求计算碳排放的方法，连硬件制造也算进去。同样的硬件上，一次典型的 Kimi K3 请求在瑞典约 0.4 克、爱尔兰 1.6 克、德国 2.5 克、德州 3.2 克。HN 上争论按地区电网算有没有意义，也有人指出推理强度能让 token 用量差两个数量级。
