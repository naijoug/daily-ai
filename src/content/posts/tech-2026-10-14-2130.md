## 新产品 / 开源
1. **pg_vectorsearch** (Timescale / TigerData): an open-source vector search extension for PostgreSQL built on the PRISM index and RaBitQ quantization; the authors claim both queries and index builds are faster than pgvector's IVFFlat / HNSW at equal recall, and it is compatible with existing `vector` / `halfvec` columns (currently alpha). [GitHub](https://github.com/timescale/pg_vectorsearch) ｜ [Announcement](https://www.tigerdata.com/blog/announcing-pg_vectorsearch-scalable-open-source-vector-search-postgresql) ｜ [HN discussion](https://news.ycombinator.com/item?id=50086165) (comments care about filtering / multi-tenancy, whether managed Postgres will integrate it, and compare it with low-memory index schemes like VectorChord)
> [zh] **pg_vectorsearch**（Timescale / TigerData）：面向 PostgreSQL 的开源向量检索扩展，主打 PRISM 索引与 RaBitQ 量化；作者称在同等召回下查询与建索引都快于 pgvector 的 IVFFlat / HNSW，并兼容已有 `vector` / `halfvec` 列（当前为 alpha）。[GitHub](https://github.com/timescale/pg_vectorsearch) ｜ [公告](https://www.tigerdata.com/blog/announcing-pg_vectorsearch-scalable-open-source-vector-search-postgresql) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50086165)（评论关心过滤/多租户能力、托管 Postgres 是否会集成，也有人拿它和 VectorChord 等低内存索引方案对比）
2. **VoiceStudio** (GitHub Trending): an open-source, fully local ElevenLabs alternative covering voice cloning, dubbing, dictation transcription and audiobooks, claiming support for many languages. [GitHub](https://github.com/debpalash/VoiceStudio)
> [zh] **VoiceStudio**（GitHub Trending）：开源、全本地的 ElevenLabs 替代方案，覆盖语音克隆、配音、听写转写与有声书等，宣称支持大量语言。
3. **CLI-Anything** (GitHub Trending / HKUDS): turns all kinds of software into CLI interfaces agents can call, and maintains CLI-Hub to make it easy to plug existing tools into agent workflows. [GitHub](https://github.com/HKUDS/CLI-Anything) ｜ [CLI-Hub](https://clianything.cc/)
> [zh] **CLI-Anything**（GitHub Trending / HKUDS）：把各类软件做成 Agent 可调用的 CLI 接口，并维护 CLI-Hub，方便把现有工具接进 Agent 工作流。
4. **Fish Audio Drama 3**: an open-weights directable TTS model (multi-speaker / emotional speech, etc.), still being updated today, suited to local or self-hosted voice experiments. [Hugging Face](https://huggingface.co/fishaudio/drama-3) ｜ [HN](https://news.ycombinator.com/item?id=50085198)
> [zh] **Fish Audio Drama 3**：开源权重的可导演 TTS 模型（多说话人 / 情绪语音等），今日仍有更新，适合本地或自托管语音实验。
5. **Geneva**: an FFmpeg-style command-line video editor written in Rust, with edits described in JSON, subtitles/graphics rendered with HTML/CSS without depending on a browser, MIT, single binary. [官网](https://genevarender.com) ｜ [Show HN](https://news.ycombinator.com/item?id=50086224)
> [zh] **Geneva**：用 Rust 写的 FFmpeg 风格命令行视频编辑器，编辑描述为 JSON，字幕/图形用 HTML/CSS 渲染且不依赖浏览器，MIT 单二进制。
6. **Building an LLM from Scratch in TypeScript**: an interactive tutorial book on Show HN that walks you through building an LLM from scratch in TypeScript / Node, suited to frontend/full-stack engineers who want to put model details into code. [Online book](https://book.humanexperiences.io/) ｜ [Show HN](https://news.ycombinator.com/item?id=50085332) (few comments; someone grumbles the chapter numbering starts at Chapter 2)
> [zh] **Building an LLM from Scratch in TypeScript**：Show HN 上的互动教程书，带你在 TypeScript / Node 里从零搭一个 LLM，适合想把模型细节落到代码里的前端/全栈工程师。[在线书](https://book.humanexperiences.io/) ｜ [Show HN](https://news.ycombinator.com/item?id=50085332)（评论不多，有人吐槽章节编号从 Chapter 2 开始）
