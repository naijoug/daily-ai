## 新产品 / 开源
1. **LFM2.5-24B-A2B**（Liquid AI）：24B 总参数、每 token 只激活 2B 的推理 MoE，专做本地 Agent，权重开放（含 Base 版），上下文从 32K 扩到 128K；官方称在 M5 Max 上 184 tokens/s，五项 Agent/工具调用基准追平或超过 Qwen3.6-35B-A3B。现在也在 HF Trending 上。[官方博客](https://www.liquid.ai/blog/lfm2-5-24b-a2b) ｜ [Hugging Face](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50097369)（实测评价分歧：有人在 ghostty 代码库里让它写个小功能，结果在编译错误里来回打转，Qwen 3.8 虽慢却做完了；也有人说知识类明显不如 Qwen 35B，但速度很香）
2. **XERJ**（GitHub Trending，今天 +725 星）：Rust 写的本地搜索索引，一条命令把代码、文档、日志、PDF 建索引，再通过 MCP 和 skill 接进 Claude Code / Cursor，让 Agent 不再一个个 grep 读文件；还主打「参考编程」，先拉下相近的开源仓库建索引，看别人怎么解决同类问题再动手。项目自称在一次对照实验里输出 token 少了 2.7 倍，解题数不变，兼容 Elasticsearch 客户端。[GitHub](https://github.com/xerj-org/xerj)
3. **caveman**（GitHub Trending，今天 +398 星）：让编程 Agent 像原始人一样少废话的 skill 加代理，少说少读、代码保持原样。项目给的数据是整段会话输入 token 少 33%，配合 Auto 模式成本降 54%、得分不变。想压 Claude Code 成本的可以看看。[GitHub](https://github.com/JuliusBrussee/caveman)
4. **Flipflop**（Show HN）：基于 Iroh 的设备间常驻加密隧道，配对一次之后随时互传文件、链接和文本，蓝牙、局域网、公网都能走，Rust + Slint 写，有 Linux / macOS / Windows / Android 版。[GitHub](https://github.com/andunieee/flipflop) ｜ [Show HN](https://news.ycombinator.com/item?id=50099136)（评论里有人问和 Tailscale Taildrop 有什么不同，也有人说自己的文件早都放进 Syncthing 了）
5. **Ito**（Show HN）：用 Lua 写声明式终端 UI 的库，底层是 Rust，作者是两个 Neovim 爱好者，嫌 JS 写的 Agent harness 不好折腾才做了它；网页 playground 里带一份可以直接丢给 LLM 的 `ito.md` 指南。[Playground](https://uji.sh/ito/) ｜ [Show HN](https://news.ycombinator.com/item?id=50096300)（有人建议多用 Lua 的免括号调用语法，写出来会更像 Lua）
