Agent编程工具开源中文社区

新产品 / 开源

  1. OpenCode 2.0：开源编程 Agent 的大版本重构。服务端现在默认作为一个后台进程常驻，TUI、网页版和桌面版都连同一个进程；API 推倒重写，Agent 还能调用自己的 API，比如开新任务时自动把会话挪进 git worktree，@opencode/client 脚本也能自动发现本地服务。发布说明 ｜ HN 讨论（有人喜欢它是少数能脱离 TUI 用的开源 Agent；也有人吐槽安装脚本因进度条渲染慢得离谱，还有人提醒升级后工具调用都走后台进程，原来包在 TUI 外面的沙箱会悄悄失效）
  2. Petal：CoScreen 原班人马做的免费开源结对编程工具，低延迟多窗口共享和远程控制，每个共享窗口在对方桌面上都是一个能拖动的原生窗口；目前支持 macOS 和 Windows，Linux 在做。官网 ｜ GitHub ｜ Show HN（Screenhero 联合创始人亲自来道贺，评论里也有人拿它和 Tuple 比，并问 LiveKit 的延迟调得怎么样）
  3. Graphicle：用 Rust 写的代码图谱加记忆工具，给 Claude Code、Codex、Cursor 等 MCP 客户端提供带文件和行号引用的上下文，全本地运行，不需要 API key，也没有遥测。GitHub ｜ Show HN（有人说自己的评测里这类记忆系统还不如直接给 ripgrep；也有人认为把记忆绑定到具体函数上、代码改了就让记忆失效，才是它真正的亮点）
  4. neckbeard：一个编程 Agent 插件，专门对付 Agent 写基础设施时胡来。由人维护一套经过 CI 测试的 OpenTofu 模块，Agent 读完仓库、问清代码回答不了的问题后，把应用映射到这些模块上，还附上每月账单估算。GitHub ｜ HN 讨论（有人质疑直接让 Agent 写 OpenTofu 加 Ansible 就行，也有人说一台 25 美元的 Hetzner 足够了）
  5. iFixAi（GitHub Trending，今天涨了 2100 多星）：独立审计 AI Agent 的工具，人或 Agent 自己都能跑，号称两分钟内回答“这个 Agent 有没有在做它该做的事”，有中文 README。GitHub
