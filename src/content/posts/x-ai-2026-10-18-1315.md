2. Google Research 开源 Harness²：不改模型权重，只自动调整 agent 周围的 8 个组件（系统提示词、护栏、记忆、工具说明、子 agent、skills、脚本、插件）来提升表现。每个任务先"提出改动、在同一任务上试跑、对比行为后合成新配置"，不需要标准答案；成功经验沉淀进跨任务的改进库。论文说一步就让 GLM-5 和 Gemini 3.5 Flash 在 WorkBuddy-Bench 上最高涨 11.5 分，执行器支持 OpenCode 和 Codex（--substrate cx），本周 GitHub 涨了约 1.5k star。https://x.com/Gorden_Sun/status/2111652432761786872 / https://github.com/google-research/harness2 / https://arxiv.org/html/2610.14224
> [en] Google Research open-sources Harness²: without changing model weights, it automatically tunes the 8 components around an agent (system prompt, guardrails, memory, tool descriptions, sub-agents, skills, scripts, plugins) to improve performance. For each task it "proposes changes, trial-runs them on the same task, compares behavior and synthesizes a new configuration", with no ground truth needed; successful experience is distilled into a cross-task improvement library. The paper says one step raises GLM-5 and Gemini 3.5 Flash by up to 11.5 points on WorkBuddy-Bench; the executor supports OpenCode and Codex (--substrate cx), and the repo gained about 1.5k GitHub stars this week.

## 有趣用法和干货
1. 像管钱包一样管 API key（Bojie Li）：他本人和服务的公司都被盗刷过多次、每次损失几千美元。做法是厂商 key 只放在一台仅内网可访问的 LiteLLM 网关上，所有服务、CI、编码 agent 都走网关；每个 key 配一个 canary 字符串，各服务在 system prompt 里预埋，网关发现请求缺 canary 就拒绝并告警，用来识别 key 被复制滥用；开发测试另发不查 canary、额度很小的 key。他还提醒 AI 部署的服务容易误监听 0.0.0.0 把家目录的 key 暴露出去。刚经历 OpenCode Console 泄露，值得照着做。https://x.com/bojie_li/status/2111666060281934142
> [en] Manage API keys like a wallet (Bojie Li): he and the company he serves have been billed fraudulently several times, thousands of dollars each time. His approach: vendor keys live only on a LiteLLM gateway reachable from the intranet, and all services, CI and coding agents go through the gateway; each key gets a canary string pre-planted in each service's system prompt, and the gateway rejects and alerts on any request missing the canary, to detect copied or abused keys; dev and test get separate small-quota keys that skip the canary check. He also warns that AI-deployed services easily mis-listen on 0.0.0.0 and expose keys in the home directory. Worth following after the OpenCode Console leak.
2. 一泽 Eze 的 Web Access Skill 更新后支持 Grok Bot：让 agent 用你本机已登录的 Chromium 系浏览器（含 Arc）做联网和采集，适合要本机登录态、非机房 IP 的任务；不依赖截图所以省 token，每探索一个网站就自动沉淀成站点 skill，下次访问更快，还能按需查本机书签和历史；Codex、Claude Code 等一次安装都能用，GitHub 约 9.2k star。https://x.com/eze_is_1/status/2111655085910696119
> [en] 一泽 Eze's Web Access Skill update now supports Grok Bot: it lets an agent browse and collect through your already-logged-in Chromium-based browser (including Arc), suited to tasks needing your local login state and non-datacenter IP; it doesn't rely on screenshots so saves tokens, automatically distills each explored site into a site skill for faster later visits, and can query local bookmarks and history on demand; one install works in Codex, Claude Code and others, about 9.2k GitHub stars.

> [en] Give agents cheap web search (向阳乔木): he wrapped DeepSeek's newly opened Search and Fetch APIs (¥5 per thousand calls) into a skill installed in one line with npx skills add, reportedly able to read WeChat official-account articles too, a replacement for expensive built-in search.
