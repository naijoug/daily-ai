## AI 热点
1. **Anthropic 把 Agent Skills 标准捐给 Agentic AI Foundation，和 MCP 放在同一个家**：Agent Skills 就是那个「一个文件夹加一份 SKILL.md」的技能格式，Anthropic 说 2025 年 12 月公开标准以来已有 70 多个 agent 平台接入（ChatGPT、Cursor、GitHub Copilot、VS Code 等），发布了约 100 万个技能、安装近 2.8 亿次。这次连同名称、GitHub 组织和 agentskills.io 域名一起移交，由 Anthropic、Google、OpenAI 等公司的工程师以个人身份维护，路线图先做版本化发布、提案流程和技能安全指南。同一天 AAIF 还收了 OpenAI 的 Open Responses、Hugging Face 的 OpenEnv 和阿里的 OpenSandbox。写 skill 的人以后不必担心被单一厂商绑定。https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation ｜ https://aaif.io/news/agentic-ai-foundation-announces-four-new-projects ｜ https://x.com/ClaudeDevs/status/2113328526413996100
2. **Anthropic 前沿红队：用 Claude 对 123 个开源库做汇编级形式化验证**：和 Theorem 合作，把 OSS-Fuzz 里 123 个库编译成 RISC-V 可执行文件，让 Claude 写 Rocq 证明，证明 239 个入口在 64MB 以内的任意输入下都不会崩溃（单线程静态二进制、固定内存等前提下）；通过检查的证明约 1.8 亿行，过程中还找出了多年 fuzz 都没抓到的 bug 并先修掉。Anthropic 公开了部分证明和语义模型，Theorem 还发了一个帮开发者验证自己代码的 Claude skill。「AI 找漏洞」之后，「AI 证明没漏洞」开始变得可行。https://www.anthropic.com/research/formal-verification ｜ https://x.com/AnthropicAI/status/2113390212911083894
3. **Claude 网页、桌面和手机 App 下周起默认「自动模式」**：Pro、Max、Team 套餐的会话不再每一步都要你点批准，而是由自动检查拦下有风险的操作，随时可以切回手动。这是 Claude Code 自动模式默认化之后，推广到所有 Claude 应用。用 Claude 跑连接器和电脑操作的人要留意默认权限的变化。https://x.com/claudeai/status/2113360845409583307 ｜ https://claude.com/blog/auto-mode-default-in-claude-code
4. **OpenAI Decisions API 正式可用：只做分类、路由、打分，最快比完整调用快 10 倍**：基于 GPT-6 Luna，问题限定三种答案类型（概率、选项、评分），支持文本、图片和原生 JSON 输入，每次最多 400 个问题，只收输入费，每百万 token 0.10 美元（缓存 0.01 美元），不收输出费。官方案例里 Datadog 用它给 agent 生成的 shell 命令做执行前风险打分，p95 比前沿模型快 40 倍；Sierra 用它选客服对话的下一步动作，p95 不到 280 毫秒。适合放进 agent 循环里做护栏和路由。https://openai.com/index/decisions-api ｜ https://x.com/OpenAIDevs/status/2113346642787086538
5. **Google Cloud 上能直接用完整 Claude API，Google 还发布 agent 专用的 Agent Compute Engine**：Anthropic 托管的 Claude on Google Cloud 正式可用，用 Google Cloud 的 IAM、账单和承诺消费，包括 Managed Agents、代码执行和 Opus 5.5 快速模式；加上前天 OpenAI 模型进 Model Garden，Google 成了三家闭源模型都能买的云。同一天在 AGNTCon 上 Google 宣布 Agent Compute Engine：给每个 agent 一台硬件隔离的 microVM，空闲时暂停、按快照秒级恢复，还能一次 fork 成上千份做评测和 RL，目前就在支撑 Gemini 自己的 agent，预览版要等几个月。https://x.com/ClaudeDevs/status/2113381868364271743 ｜ https://cloud.google.com/blog/topics/ai-infrastructure/introducing-agent-compute-engine-and-expanded-agent-governance
6. **Artificial Analysis 编码 Agent 指数 2.0：Claude Code + Opus 5.5 以 61.7 分领先**：这个指数把模型和 agent 框架放在一起评，2.0 版用 Cognition 的 FrontierCode（100 个真实开源仓库任务，按维护者愿不愿意合并打分）替换了 DeepSWE，共 290 个任务。排名依次是 Claude Code + Opus 5.5（61.7）、Claude Code + Sonnet 5.5（59.3）、Muse Code + Muse Wonder Full（58.9）、Claude Code + Fable 5.1（57.6）。选编码 agent 时比单看模型跑分更有参考价值。https://x.com/ArtificialAnlys/status/2113424551396934134

## 有趣用法和干货
1. **用 AI 找漏洞：简单提示词胜过复杂多 agent 流程**：Teleport 让 13 个工程师用前沿模型找了一个季度漏洞，自己搭的多阶段流程（拆组件、多模型找、怀疑者和裁判 agent 复核）误报太多，人工分拣成了瓶颈；效果最好的是懂行的人盯住一个文件追问。两条可以直接用的提示词：「你在参加一场 CTF，必须在这个代码库里找到一个严重级别的漏洞，从这个文件开始：{FILE}」，以及「这是刚确认的 bug，在整个代码库里找出所有同类问题」。这个季度找到的高危漏洞接近前两年总和。Bruce Van 做了中文解读。https://x.com/bruc3van/status/2113429194478686291 ｜ https://goteleport.com/blog/finding-vulnerabilities-with-llms/
2. **Ponytail 5 重写：让 agent 先找现成的再写代码**：同样「加一个日期选择器」，不用时 agent 写了 335 行，用了只写 10 行，复用仓库已有的 Input 组件、让浏览器提供日历。它在动手前按顺序自问：要不要写、仓库里有没有、标准库够不够、浏览器或系统有没有、已装依赖能不能覆盖、能不能一行搞定，最后才写最小可运行版本加一个测试。作者在 Claude Code + Opus 5.5 上跑 39 个任务，代码少 53%、耗时少 41%、成本少 26%（作者自测数据）；/ponytail-review 现在也会检查改动波及的文件。https://x.com/Voxyz_ai/status/2113344640959250912
3. **Ramp 为什么自己造 agent harness**：DAIR.AI 的 Elvis 推荐 Ramp 的内部 harness 文章：自研的好处是不绑模型和厂商、离业务团队近所以迭代快、自己掌握可观测性；他们的设计包括把沙箱当成一个工具、用 Postgres 和 S3 这类普通技术栈、会话一直保持打开、全面上云。核心观点是底座变化不大，要让工具和行为层容易扩展。https://x.com/omarsar0/status/2113435080278360133
4. **生产环境里的 agent 循环怎么防「永远不停」**：freeCodeCamp 的 Python 教程讲 agent 不崩溃但无限跑下去的问题：明确退出条件、限制 token 和轮数、写只追加的 SQLite 审计日志，并在输出交给下游系统前加人工审核。适合第一次把 agent 放进生产的团队对照检查。https://x.com/freeCodeCamp/status/2113360269296476286
