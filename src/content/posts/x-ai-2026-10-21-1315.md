## 有趣用法和干货
1. Have the agent draw a state diagram and then formally verify (lauren/poteto, 1.7k likes, 1.8k bookmarks): first have the agent draw the feature's user flow as a statechart, then use the /create-formal-verification-skill generated by pstack to find bugs with tools like TLA+. It helps you understand the code and user flows, and fix problems before users hit them. https://x.com/poteto/status/2112736749281759566
> [zh] 让 agent 画状态图再做形式化验证（lauren/poteto，1.7k 赞、1.8k 收藏）：先让 agent 把功能的用户流程画成 statechart，再用 pstack 生成的 /create-formal-verification-skill，借 TLA+ 之类的工具找 bug。既能弄懂代码和用户流程，又能在用户撞上之前修掉问题。
2. Uber 用 agent 安全删代码（meng shao 解读）：AutoClean 已清理 1.6 万多个过期 feature flag、100 多万行代码。做法是条件化简交给确定性引擎（通过 MCP 调用），agent 只做传播判断；修 CI 时测试修复器只能改测试文件，防止它改生产代码让测试通过；最后由多个专职审查 agent 并行检查「只删不增、语义不变、不越界、不留 agent 痕迹」，任一失败就丢掉这个 diff。https://x.com/shao__meng/status/2112723092468605242 ｜ https://x.com/UberEng/status/2112604623454470476
> [en] Uber uses agents to delete code safely (meng shao's write-up): AutoClean has removed 16,000+ stale feature flags and over a million lines of code. Condition simplification goes to a deterministic engine (called via MCP) and the agent only decides propagation; when fixing CI the test fixer may only edit test files, preventing it from changing production code to make tests pass; finally several specialized review agents check in parallel that the change is "delete-only, semantics unchanged, in scope, no agent traces", and any failure discards the diff.
3. Databricks MemCurrent 的 agent 记忆设计（meng shao 解读）：原始会话轨迹只追加不修改；提炼出的经验存成分层文件，顶部有一份自动生成的 memory.md 索引，会话开始先注入索引，需要时再检索。消融实验显示大部分提升来自「派生记忆加索引」（无记忆 22.3%，派生记忆加索引 66.1%，两者结合 68.4%）。https://x.com/shao__meng/status/2112726961885962486
> [en] Databricks MemCurrent's agent memory design (meng shao's write-up): raw session traces are append-only; distilled experience is stored as layered files with an auto-generated memory.md index at the top, injected at session start and retrieved from as needed. Ablations show most of the gain comes from "derived memory plus index" (no memory 22.3%, derived memory plus index 66.1%, both combined 68.4%).
4. Supabase releases a skill for coding agents: the agent can query project logs directly, and the skill tells it to focus on error spikes, security issues, slow queries and usage growth, with you deciding when it runs. https://x.com/supabase/status/2112578077872050470
> [zh] Supabase 发布给编码 agent 用的 skill：agent 可以直接查项目日志，skill 告诉它重点看错误激增、安全问题、慢查询和用量增长，运行时机由你决定。
