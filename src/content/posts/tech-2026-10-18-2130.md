## 新产品 / 开源
1. **Sphinx (Show HN): before pushing AI-written code, it quizzes you on whether you understood it**: a Git hook that, when you push a protected branch, has a reviewer model that hasn't seen your conversation with the agent read the diff and pose a "what happens when this fails" scenario question; a wrong answer gets an explanation and a new question, and only a right answer lets the push through. Supports Codex, Claude Code, Cursor, OpenCode, Pi or plain Git, and connects to OpenRouter or any OpenAI-compatible endpoint; your answers aren't passed to the coding agent, and it doesn't read .env or secrets; if you're in a hurry you can skip with `sphinx yolo`, which leaves a record. MIT, `npm install -g sphinx-understand`. [Website](https://sphinx-six-theta.vercel.app/) ｜ [GitHub](https://github.com/parthh01/sphinx) ｜ [HN discussion](https://news.ycombinator.com/item?id=50137950) (173 points. Comments are mostly skeptical: people who care about code already read it, those who don't will just click through, and it causes "confirmation fatigue"; someone grumbles the name clashes with the Sphinx docs tool; others think not understanding the code has always been a problem, and this is more constructive than just bashing AI-generated code)
> [zh] **Sphinx（Show HN）：推送 AI 写的代码前，先考考你看懂没有**：一个 Git hook，在你推送受保护分支时，让一个没看过你和 Agent 对话的审查模型读 diff，出一道「出错时会怎样」的情景题，答错就讲解再换一题，答对才放行。支持 Codex、Claude Code、Cursor、OpenCode、Pi 或纯 Git，可以接 OpenRouter 或任意 OpenAI 兼容接口；你的回答不会传给编码 Agent，也不会读 .env 和密钥，赶时间可以 `sphinx yolo` 跳过但会留记录。MIT，`npm install -g sphinx-understand`。[官网](https://sphinx-six-theta.vercel.app/) ｜ [GitHub](https://github.com/parthh01/sphinx) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50137950)（173 分。评论以质疑为主：在乎代码的人本来就会读，不在乎的人只会点过去，还会导致「确认疲劳」；有人吐槽名字和 Sphinx 文档工具撞了；也有人认为不理解代码一直是问题，比一味骂 AI 生成的代码有建设性）
2. **Husk 2.0: run Android games directly on iPhone without a jailbreak**: an open-source project by indie developer Leviidev. It doesn't emulate a full Android system; instead it packs an ART compiled for iOS, bionic interfaces mapped onto iOS and a custom .so loader into an ordinary iOS app process, so the 64-bit native code in an APK runs directly on the iPhone CPU; graphics are translated through ANGLE (OpenGL ES) and MoltenVK (Vulkan). Supports iOS 16+, imports APK/XAPK/APKM/APKS, is compatible with engines like Unity, UE4 and Godot 3/4, and already works with 150+ apps. The hurdles are that you need to sideload, enable JIT through something like a debugger, and can run only one app at a time. About 2.3k GitHub stars, GPL-2.0. [GitHub](https://github.com/Leviidev/Husk) ｜ [IT之家](https://www.ithome.com/1/014/576.htm)
> [zh] **Husk 2.0：不用越狱，在 iPhone 上直接跑 Android 游戏**：独立开发者 Leviidev 的开源项目。它不模拟整套 Android 系统，而是把编译到 iOS 的 ART、映射到 iOS 的 bionic 接口和自研 .so 加载器塞进一个普通 iOS 应用进程里，让 APK 里的 64 位原生代码直接在 iPhone CPU 上执行；图形靠 ANGLE（OpenGL ES）和 MoltenVK（Vulkan）转换。支持 iOS 16+，能导入 APK/XAPK/APKM/APKS，兼容 Unity、UE4、Godot 3/4 等引擎，已兼容 150 多款应用。门槛在于要侧载、要靠调试器之类的方式开 JIT，一次只能跑一款应用。GitHub 约 2.3k 星，GPL-2.0。
3. **BeatBrowser: let Codex, Claude Code and Cursor share the Chrome you're using**: an open-source project from V2EX "Share Creations", a Chrome extension plus a local Node bridge that lets multiple agents operate your logged-in Chrome through MCP (also a CLI and Node SDK). Each task opens its own window, and automation pauses as soon as you click in; you can take over or stop from the side panel, and one-click cleanup closes only the pages the agent opened; it hands the page back to you for QR scans, captchas and 2FA. It has 24 MCP tools, `act` supports batched steps, conditions and loops, and site learnings are stored locally in `~/.beat-browser/learnings/`; no cookie export, no cloud service or telemetry, and cloud agents can use your local browser through your own Cloudflare Tunnel. MIT, and the project is very new (a dozen or so stars). [GitHub](https://github.com/BeatAPI/BeatBrowser) ｜ [V2EX](https://www.v2ex.com/t/1249726)
> [zh] **BeatBrowser：让 Codex、Claude Code、Cursor 共用你正在用的 Chrome**：V2EX「分享创造」里的开源项目，一个 Chrome 扩展加本地 Node 桥接，通过 MCP（也有 CLI 和 Node SDK）让多家 Agent 操作你已登录的那个 Chrome。每个任务开独立窗口，你一点进去自动化就暂停，可在侧边栏接管或停止，一键清理只关 Agent 开的页面；遇到扫码、验证码、2FA 会把页面交回给人。有 24 个 MCP 工具，`act` 支持批量步骤、条件和循环，站点经验存在本地 `~/.beat-browser/learnings/`；不导出 Cookie、无云服务和遥测，云端 Agent 可以走你自己的 Cloudflare Tunnel 来用本机浏览器。MIT，项目还很新（十几颗星）。
