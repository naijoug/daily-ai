## 新产品 / 开源
1. **Sphinx（Show HN）：推送 AI 写的代码前，先考考你看懂没有**：一个 Git hook，在你推送受保护分支时，让一个没看过你和 Agent 对话的审查模型读 diff，出一道「出错时会怎样」的情景题，答错就讲解再换一题，答对才放行。支持 Codex、Claude Code、Cursor、OpenCode、Pi 或纯 Git，可以接 OpenRouter 或任意 OpenAI 兼容接口；你的回答不会传给编码 Agent，也不会读 .env 和密钥，赶时间可以 `sphinx yolo` 跳过但会留记录。MIT，`npm install -g sphinx-understand`。[官网](https://sphinx-six-theta.vercel.app/) ｜ [GitHub](https://github.com/parthh01/sphinx) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50137950)（173 分。评论以质疑为主：在乎代码的人本来就会读，不在乎的人只会点过去，还会导致「确认疲劳」；有人吐槽名字和 Sphinx 文档工具撞了；也有人认为不理解代码一直是问题，比一味骂 AI 生成的代码有建设性）
2. **Husk 2.0：不用越狱，在 iPhone 上直接跑 Android 游戏**：独立开发者 Leviidev 的开源项目。它不模拟整套 Android 系统，而是把编译到 iOS 的 ART、映射到 iOS 的 bionic 接口和自研 .so 加载器塞进一个普通 iOS 应用进程里，让 APK 里的 64 位原生代码直接在 iPhone CPU 上执行；图形靠 ANGLE（OpenGL ES）和 MoltenVK（Vulkan）转换。支持 iOS 16+，能导入 APK/XAPK/APKM/APKS，兼容 Unity、UE4、Godot 3/4 等引擎，已兼容 150 多款应用。门槛在于要侧载、要靠调试器之类的方式开 JIT，一次只能跑一款应用。GitHub 约 2.3k 星，GPL-2.0。[GitHub](https://github.com/Leviidev/Husk) ｜ [IT之家](https://www.ithome.com/1/014/576.htm)
3. **BeatBrowser：让 Codex、Claude Code、Cursor 共用你正在用的 Chrome**：V2EX「分享创造」里的开源项目，一个 Chrome 扩展加本地 Node 桥接，通过 MCP（也有 CLI 和 Node SDK）让多家 Agent 操作你已登录的那个 Chrome。每个任务开独立窗口，你一点进去自动化就暂停，可在侧边栏接管或停止，一键清理只关 Agent 开的页面；遇到扫码、验证码、2FA 会把页面交回给人。有 24 个 MCP 工具，`act` 支持批量步骤、条件和循环，站点经验存在本地 `~/.beat-browser/learnings/`；不导出 Cookie、无云服务和遥测，云端 Agent 可以走你自己的 Cloudflare Tunnel 来用本机浏览器。MIT，项目还很新（十几颗星）。[GitHub](https://github.com/BeatAPI/BeatBrowser) ｜ [V2EX](https://www.v2ex.com/t/1249726)
4. **500 个时钟，全由 Opus 5.5 生成（Show HN）**：作者平时用「让模型写一个自包含网页时钟」来测前沿模型，类似 Simon Willison 的「骑自行车的鹈鹕」，这次在 Claude 聊天界面里分几轮让 Opus 5.5 做了 500 个，塞进一个 6.3 MB 的 HTML 文件。仓库里有 Claude 自己写的提示过程和页面设计总结，想看模型前端创意上限的可以翻翻。[在线页面](https://tkgally.github.io/500-clocks/) ｜ [GitHub](https://github.com/tkgally/500-clocks/tree/main) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50137820)（有人很喜欢 Pong 时钟和文字冒险时钟；也有人觉得不少作品和时间没什么关系，比如洛伦兹吸引子那个）
5. **Open MicroManipulator：DIY 亚微米级三维运动平台**：开源的三轴精密运动控制平台，号称能做到亚微米级定位，作者在 YouTube 有整个制作系列。偏硬件，但对做显微、实验室自动化或精密机械的人很有参考价值。[GitHub](https://github.com/0x23/MicroManipulatorStepper) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50140001)（评论称作者是「传奇」，做出来放到 YouTube 就消失了，也不推广）
