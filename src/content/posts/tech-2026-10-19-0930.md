## 新产品 / 开源
1. **HybridAgent：在隐空间里想、用文本调工具的 Agent**：斯坦福、Together AI、UIUC 的论文和开源代码。它用一个轻量的 HybridLink 让模型在同一次生成里在「隐式推理」和「文本交互」之间切换，多轮对话间保留连续的工作记忆，调工具仍走文本，隐式思考也可以被解读。训练上先用 HybridSFT 稳住，再用 HybridRL 学会什么时候在隐空间里想、什么时候用文本动手。论文报告在 3 个模型规模、11 个数学、科学、医学、搜索和 Agent 基准上平均提升 10.4%，token 少 35.5%–54.7%，推理快 1.8–2.6 倍，成本低 2.7–3.7 倍。[arXiv](https://arxiv.org/abs/2610.18861) ｜ [GitHub](https://github.com/togethercomputer/HybridAgent) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50145337)（约 200 分。有人追问基准细节，想知道它只是省 token 还是真能提准确率；有人设想更彻底的做法，文本模式下也同时传入隐向量；也有人反对用「思考」形容 LLM）
2. **Free Pascal 和 Lazarus 终于有了动态包**：作者称这个功能在 FPC 生态里拖了 20 多年。动态包就是带额外元数据的普通共享库（Linux、Windows、macOS 都支持），装控件和 IDE 扩展不用再重新编译整个 Lazarus，自己的程序也能用它做插件系统，运行时可以替换；运行时还处理了线程变量、字符串和动态数组在主程序和包之间传递的问题。[官网](https://www.getlazarus.org/dynamic/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50144066)（有人指出这个站是 Lazarus 的一个分叉，官方是 lazarus-ide.org；也有人抱怨 FPC 至今仍要在块开头声明变量）
3. **Mitos：从 Helix 分叉出来的模态编辑器**：和 Helix 一样「先选再操作」，自带多光标、tree-sitter、LSP、DAP 调试，还能在终端里预览图片。作者说分叉是为了更快地试新功能和不同的架构，现阶段稳定性会差一些，可能有破坏性变更。[官网](https://mitos.computer/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50143132)（评论最多的问题是「和 Helix 到底差在哪」，官网没讲清；也有人借机发问，Rust 写跨平台原生 GUI 已经不难了，为什么还要做大型 TUI）
4. **WhatsApp MCP，免费跑在 Cloudflare 上（Show HN）**：作者想让手机上的 Claude 读自己的 WhatsApp，又不想用 WhatsApp Business 或自己架服务器跑 Baileys，于是做了这个能跑在 Cloudflare 免费额度上的个人版 MCP，还会连你的 Google 账号拿联系人名字，不然很多人只显示号码、搜索也不好用。作者自己说这是灰色地带，所以只做单用户安装，建议直接让 Agent 照着仓库部署。[GitHub](https://github.com/finereli/whatsapp-mcp) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50145715)（最高赞担心对方的消息也被传给 AI 公司，聊天的另一方并没有同意；有人说用 whatsmeow 这类非官方方案时不时会被封号，在 WhatsApp 是主要联系方式的国家很麻烦）
5. **RepRapMicron（μRepRap）：用常见材料 DIY 微米级 3D 打印机**：目标是做一台能自我复制、精度到微米甚至亚微米的 RepRap，柔性结构来自 OpenFlexure 显微平台的思路。目前推荐的 PIKA V0.02 在大约 8 mm 见方的空间里能做到约 1 μm 的重复定位和 10 μm 以内的精度，沉积过 4 μm 的 UV 树脂液滴，用 4 μm 层高打出了 0.5 mm 的 Benchy。和昨晚那期写过的 Open MicroManipulator 是同一类方向。[项目 Wiki](https://github.com/VikOlliver/RepRapMicron/wiki) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50141076)（329 分。有人类比 18 世纪末 Ramsden、Maudslay 把精密刻度和螺纹从手艺变成工业；也有人吐槽项目用的 USB 显微镜质量很差；还有人调侃「18 个月后就能自己造内存了」）

## 中文社区
1. **V2EX：流量喵加了磁盘监控，看看 AI 工具到底写了多少盘**：作者在家里的 Mac mini 上常开 Codex、Claude Code、Cursor、Gemini，看到 Codex 持续写盘的反馈后，给自己的菜单栏流量工具加了按进程的读写排行（今日、7 天、30 天、累计，可导出 CSV）、SMART 和累计写入等磁盘状态、菜单栏实时读写。Swift 原生，MIT，数据只在本机。作者也提醒进程 I/O 不等于 SSD 实际写入。昨天那期写过 Codex 桌面版 Crashpad 转储写满硬盘的问题，用 Mac 的可以装上看看。[V2EX](https://www.v2ex.com/t/1249859)
2. **V2EX：Agent8，让只有 Java 8 的 AIX、HP-UX、Solaris 继续当新版 Jenkins 的节点**：银行、电信、制造业的老问题：Jenkins 把 agent 的 Java 要求一路抬到 21，而 AIX 7.1、HP-UX 最高只有 Java 8，controller 一升级老构建机就连不上。作者用 JvmDowngrader 把官方 agent.jar 降级成 Java 8 字节码，再处理新版 class、serialVersionUID 变化、OpenJ9 和 IBMJCE 签名 provider 等兼容问题，老机器仍是正常节点，sh、junit、stash、Git checkout 都能用。Linux 上的 HotSpot 8、OpenJ9 8 每次改动都在 CI 里跑，Solaris 和 HP-UX 安腾真机能连上但完整构建还没验证，作者最想要 AIX 的反馈。MIT。[V2EX](https://www.v2ex.com/t/1249844) ｜ [GitHub](https://github.com/keelinfra/agent8)
