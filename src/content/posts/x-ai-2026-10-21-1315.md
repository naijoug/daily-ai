## 有趣用法和干货
1. 让 agent 画状态图再做形式化验证（lauren/poteto，1.7k 赞、1.8k 收藏）：先让 agent 把功能的用户流程画成 statechart，再用 pstack 生成的 /create-formal-verification-skill，借 TLA+ 之类的工具找 bug。既能弄懂代码和用户流程，又能在用户撞上之前修掉问题。https://x.com/poteto/status/2112736749281759566
2. Uber 用 agent 安全删代码（meng shao 解读）：AutoClean 已清理 1.6 万多个过期 feature flag、100 多万行代码。做法是条件化简交给确定性引擎（通过 MCP 调用），agent 只做传播判断；修 CI 时测试修复器只能改测试文件，防止它改生产代码让测试通过；最后由多个专职审查 agent 并行检查「只删不增、语义不变、不越界、不留 agent 痕迹」，任一失败就丢掉这个 diff。https://x.com/shao__meng/status/2112723092468605242 ｜ https://x.com/UberEng/status/2112604623454470476
3. Databricks MemCurrent 的 agent 记忆设计（meng shao 解读）：原始会话轨迹只追加不修改；提炼出的经验存成分层文件，顶部有一份自动生成的 memory.md 索引，会话开始先注入索引，需要时再检索。消融实验显示大部分提升来自「派生记忆加索引」（无记忆 22.3%，派生记忆加索引 66.1%，两者结合 68.4%）。https://x.com/shao__meng/status/2112726961885962486
4. Supabase 发布给编码 agent 用的 skill：agent 可以直接查项目日志，skill 告诉它重点看错误激增、安全问题、慢查询和用量增长，运行时机由你决定。https://x.com/supabase/status/2112578077872050470
