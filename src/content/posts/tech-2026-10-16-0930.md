## 新产品 / 开源
1. **Krea 3** (open beta): an image foundation model pitched on "precise editing at scale": regional edits that disturb surrounding pixels as little as possible, with the company saying speed and cost are far below comparable frontier image models; the founder posted personally on HN. The team says it will consider LoRA fine-tuning and open weights but is still dealing with launch turbulence. [Website](https://www.krea.ai/krea-3) ｜ [HN discussion](https://news.ycombinator.com/item?id=50105648) (248 points / 83 comments: some compare it with GPT-Image on UI generation and praise small-text detail; others grumble about trial credits, dark-mode pricing, and occasional "AI texture")
> [zh] **Krea 3**（开源 beta）：主打「可规模化的精准编辑」的图像基础模型——区域编辑、尽量少伤周边像素，官方称速度和成本都远低于同类 frontier 图模；创始人在 HN 亲自发帖。团队表示会考虑 LoRA 微调与开源权重，但目前还在扛发布抖动。[官网](https://www.krea.ai/krea-3) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50105648)（248 分 / 83 评：有人拿它和 GPT-Image 比 UI 出图，夸小字细节；也有人吐槽试用额度、暗模式定价，以及仍然偶发「AI 纹理」）
2. **REA** (near the top of GitHub's daily trending): uses an agent for reverse engineering, digging from application behavior all the way to the native binary and then reproducing the implementation as far as possible; the Chinese community (Juejin, V2EX, Ruan Yifeng's weekly) has been abuzz about it these two days. Ruan Yifeng also raised a worry: if even binaries can be replicated by AI, software may become reluctant to be shipped to users' machines and only be locked in the cloud. [GitHub](https://github.com/morluto/rea) ｜ [V2EX 相关讨论](https://www.v2ex.com/t/1249200)
> [zh] **REA**（GitHub Trending 日榜前列）：用 Agent 做逆向——从应用行为一路挖到原生二进制，再尽量复刻实现；中文社区（掘金、V2EX、阮一峰周刊）这两天也在刷。阮一峰还提到一种担忧：如果二进制都能被 AI 复刻，软件可能更不敢下发到用户机器、只能锁在云端。
3. **NVIDIA Nemotron 3.5 Super VL**: an open multimodal agent model, 120B MoE with about 12B active per token, putting reasoning, tool calling and text/image/document/video understanding in one pipeline; NVIDIA says single-card agent throughput can be about 5x that of open models of similar size, and Scale / Ramp / AI21 and others are already doing post-training. Also comes with smaller siblings such as Bolt. [NVIDIA 博客](https://developer.nvidia.com/blog/nvidia-nemotron-3-5-super-vl-powers-specialized-agents-with-multimodal-reasoning/) ｜ [HF Bolt 示例](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB)
> [zh] **NVIDIA Nemotron 3.5 Super VL**：开源多模态 Agent 模型，120B MoE、每 token 激活约 12B，把推理、工具调用和文/图/文档/视频理解塞进同一条流水线；官方称单卡 agent 吞吐可比同体量开源模型高约 5×，Scale / Ramp / AI21 等已在做后训练。还带 Bolt 等更小兄弟型号。
4. **Perplexity SPACE**: an open-source agent code-sandbox platform (Sandboxed Platform for Agentic Code Execution) with pluggable runtimes for isolating agent / user code; the blog page is blocked by Cloudflare, but the repo can be viewed directly. [GitHub](https://github.com/perplexityai/SPACE)
> [zh] **Perplexity SPACE**：开源的 Agent 代码沙箱平台（Sandboxed Platform for Agentic Code Execution），可插拔运行时，用来隔离跑 Agent / 用户代码；博客页有 Cloudflare 拦，仓库可直接看。

1. **Goodfire / Nick Cammarata: "Neural Networks Are Already Clean"**: a long essay arguing that early evidence for "polysemantic neurons / superposition" was mostly misread, and the real cause looks more like traceable recursive generalization; most neurons in modern models are actually readable, so the outlook for interpretability may be rosier than thought. It shot to about 500 points on HN overnight. [Original](https://already-clean.goodfire.com/) ｜ [HN discussion](https://news.ycombinator.com/item?id=50105647) (some treat it as a breakthrough, others warn against over-extrapolating)
> [zh] **Goodfire / Nick Cammarata：《Neural Networks Are Already Clean》**：长文主张早期「多义神经元 / 叠加（superposition）」证据多半被误读，真实主因更像可追踪的递归泛化；现代模型里大部分神经元其实可读，可解释性前景可能比想象乐观。HN 隔夜冲到约 500 分。[原文](https://already-clean.goodfire.com/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50105647)（有人当作突破，也有人提醒别过度外推）
