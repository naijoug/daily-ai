## 新产品 / 开源
1. **LFM2.5-24B-A2B** (Liquid AI): a reasoning MoE with 24B total parameters and only 2B active per token, built for local agents, with open weights (including a Base version) and context extended from 32K to 128K; the company says 184 tokens/s on an M5 Max and matches or beats Qwen3.6-35B-A3B on five agent/tool-calling benchmarks. Now also on HF Trending. [Official blog](https://www.liquid.ai/blog/lfm2-5-24b-a2b) ｜ [Hugging Face](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B) ｜ [HN discussion](https://news.ycombinator.com/item?id=50097369) (hands-on opinions differ: one had it write a small feature in the ghostty codebase and it went in circles over compile errors while Qwen 3.8, though slow, finished; another says knowledge tasks are clearly worse than Qwen 35B but the speed is great)
> [zh] **LFM2.5-24B-A2B**（Liquid AI）：24B 总参数、每 token 只激活 2B 的推理 MoE，专做本地 Agent，权重开放（含 Base 版），上下文从 32K 扩到 128K；官方称在 M5 Max 上 184 tokens/s，五项 Agent/工具调用基准追平或超过 Qwen3.6-35B-A3B。现在也在 HF Trending 上。[官方博客](https://www.liquid.ai/blog/lfm2-5-24b-a2b) ｜ [Hugging Face](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50097369)（实测评价分歧：有人在 ghostty 代码库里让它写个小功能，结果在编译错误里来回打转，Qwen 3.8 虽慢却做完了；也有人说知识类明显不如 Qwen 35B，但速度很香）
2. **XERJ** (GitHub Trending, +725 stars today): a local search index written in Rust that indexes code, docs, logs and PDFs with one command, then plugs into Claude Code / Cursor via MCP and skill so the agent stops grepping through files one by one; it also pushes "reference programming": first pull down and index similar open-source repos, see how others solved the same kind of problem, then start. The project claims 2.7x fewer output tokens in one controlled experiment with the same number of problems solved, and is compatible with Elasticsearch clients. [GitHub](https://github.com/xerj-org/xerj)
> [zh] **XERJ**（GitHub Trending，今天 +725 星）：Rust 写的本地搜索索引，一条命令把代码、文档、日志、PDF 建索引，再通过 MCP 和 skill 接进 Claude Code / Cursor，让 Agent 不再一个个 grep 读文件；还主打「参考编程」，先拉下相近的开源仓库建索引，看别人怎么解决同类问题再动手。项目自称在一次对照实验里输出 token 少了 2.7 倍，解题数不变，兼容 Elasticsearch 客户端。
3. **caveman** (GitHub Trending, +398 stars today): a skill plus proxy that makes coding agents say less, like a caveman: talk less, read less, keep code unchanged. The project's numbers are 33% fewer input tokens over a whole session, and with Auto mode 54% lower cost at the same score. Worth a look if you want to cut Claude Code costs. [GitHub](https://github.com/JuliusBrussee/caveman)
> [zh] **caveman**（GitHub Trending，今天 +398 星）：让编程 Agent 像原始人一样少废话的 skill 加代理，少说少读、代码保持原样。项目给的数据是整段会话输入 token 少 33%，配合 Auto 模式成本降 54%、得分不变。想压 Claude Code 成本的可以看看。
4. **Flipflop** (Show HN): a persistent encrypted tunnel between devices built on Iroh; after pairing once, you can send files, links and text at any time over Bluetooth, LAN or the internet, written in Rust + Slint, with Linux / macOS / Windows / Android versions. [GitHub](https://github.com/andunieee/flipflop) ｜ [Show HN](https://news.ycombinator.com/item?id=50099136) (in comments someone asks how it differs from Tailscale Taildrop, and another says his files are all in Syncthing already)
> [zh] **Flipflop**（Show HN）：基于 Iroh 的设备间常驻加密隧道，配对一次之后随时互传文件、链接和文本，蓝牙、局域网、公网都能走，Rust + Slint 写，有 Linux / macOS / Windows / Android 版。[GitHub](https://github.com/andunieee/flipflop) ｜ [Show HN](https://news.ycombinator.com/item?id=50099136)（评论里有人问和 Tailscale Taildrop 有什么不同，也有人说自己的文件早都放进 Syncthing 了）
5. **Ito** (Show HN): a library for writing declarative terminal UIs in Lua, with Rust underneath; the authors are two Neovim enthusiasts who found JS-written agent harnesses hard to tinker with, so they built it; the web playground includes an `ito.md` guide you can hand straight to an LLM. [Playground](https://uji.sh/ito/) ｜ [Show HN](https://news.ycombinator.com/item?id=50096300) (someone suggests using Lua's parenthesis-free call syntax more so it reads more like Lua)
> [zh] **Ito**（Show HN）：用 Lua 写声明式终端 UI 的库，底层是 Rust，作者是两个 Neovim 爱好者，嫌 JS 写的 Agent harness 不好折腾才做了它；网页 playground 里带一份可以直接丢给 LLM 的 `ito.md` 指南。[Playground](https://uji.sh/ito/) ｜ [Show HN](https://news.ycombinator.com/item?id=50096300)（有人建议多用 Lua 的免括号调用语法，写出来会更像 Lua）

> [en] **V2EX "Share Creations": two agent-engineering projects**: OpenNavo is an open-source macOS Homebrew GUI store (Tauri 2 + Vue 3 + Rust, Go backend), where the author hands as much daily development and maintenance as possible to agents and even built a dedicated MCP backend interface for them; EverAgent is a persistent agent harness that writes conversations, model turns, tool calls and checkpoints to SQLite first, so it can resume from a checkpoint if the process crashes.

> [en] **NetBSD received a record $120,000 in donations last month**: more than double its $50,000 goal; The Register thinks it's because the Linux world is embracing AI more and more, leading people who want to avoid AI to support NetBSD instead.
