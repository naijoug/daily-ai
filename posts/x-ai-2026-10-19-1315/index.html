AI 热点

  1. OpenCode Console 泄露有了后续：OpenAI Codex 负责人 Tibo 说 OpenAI 已和 OpenCode 一起，让同时是 OpenAI API 客户的受影响用户恢复使用，被攻击盗刷的额度都会退回；他还提到可以申请 Daybreak Blue，用 OpenAI 偏宽松的网络安全配置做防御，劝大家别等出事再找。帖子 2.3k+ 赞。https://x.com/thsottiaux/status/2112034063934742720
  2. 阿里通义 MAI-UI 团队开源 OpenGCUA，一整套“通用计算机使用 agent”技术栈（harness、跨设备 SDK、原生 macOS 应用、评测轨迹、参考 agent）。思路是不再每步截图点按钮，而是让模型自己决定什么时候截图，并写带循环和判断的 Python 程序，把 GUI 操作、应用 API 和 shell 命令编排在一起。meng shao 转述论文：OSWorld-v2 上 8 个模型平均分从 45.3 升到 64.9，步数平均少 53%，弱模型涨得最多。https://x.com/shao__meng/status/2111999471588679916 / https://github.com/Tongyi-MAI/OpenGCUA
  3. 网易 LobsterAI 发布《中国办公 Agent 用户行为报告》，结论和 X 上的印象很不一样：微信是最大的办公 agent 入口（77%，飞书 14.3%），最大使用场景仍是泛编程/IT，73.6% 的普通用户只用一个模型，最常见组合是 DeepSeek Flash 搭 GLM 5.3 Flash。铁锤人补充说国庆期间 agent 使用高峰从下午 4 点推到了晚上 10 点。https://x.com/vista8/status/2112029104060948920 / https://x.com/lxfater/status/2112000879314326001
  4. DeepSeek-V4.1-Flash-1017 新进展：智东西转述，它（Max 档）已经是 Code Arena WebDev 榜开源第一，总榜第 12（1670 分），排在 Claude Opus 5 (High) 前面，成本约为 Kimi K3 的十分之一。花叔也发了一份价格报告的解读，讲它为什么体感最便宜。https://x.com/Chinazhidx/status/2112030651897823586 / https://x.com/AlchainHust/status/2112013425890951623

有趣用法和干货

  1. 多 agent 编程怎么省钱（Cohere 新论文，Rohan Paul 转述）：agent 团队比单个 agent 强，但成本是 3 到 7 倍。实验发现只让子 agent 做调研和规划、不让它们写代码，效果和全流程参与持平，成本减半；用最强模型（GPT-5.6 Sol）当主 agent、配 16 个便宜的 Luna 做规划，只比全用 Sol 低 1.4 分，成本少 70%。反过来让便宜模型写代码会拉低效果。对你配 subagent 很直接：贵模型留给主 agent 写代码，探索和规划交给便宜模型。https://x.com/rohanpaul_ai/status/2112048784457060471
  2. tv-vibehack（Gorden Sun 推荐）：作者用 Claude Code 给父母的小米电视做了个去广告启动器，不用 root、不插线，电脑和电视连同一个 Wi-Fi、电视开调试模式就能装；装完主界面变成纯黑极简风，没有开机广告和推送，启动器只有 1.6MB、纯 Java，1G 内存的老电视也能跑。周末给家里电视动手的好项目。https://x.com/Gorden_Sun/status/2112020428210467230 / https://github.com/Gathin23/tv-vibehack
  3. Thorsten Ball（Amp 工程师）给初级工程师的回信：他说自己过去花时间练的东西大概有三到五成已经不太重要了，比如 Vim、冷门命令行和语法、标准库细节；不管模型多会写代码，一直有价值的是四样：知道做什么、为什么做；对从业务问题到客户价值的整条链路负责；系统思维（他现在给 agent 写提示词时想的是系统各部分怎么交互，而不是代码）；以及把文字写好。https://x.com/thorstenball/status/2112046496396833255
