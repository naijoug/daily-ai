## 新产品 / 开源
1. **FLUX 3 Image Klein**（Black Forest Labs）：5.6B 参数的开放权重图像模型，文生图、图像编辑、最多 10 张参考图的多参考生成都能做，和完整版 FLUX 3 一样支持原生 4K 和用边界框控制元素位置 / 限定编辑区域。同时放出可微调的 base 版和低延迟的步数蒸馏版，还有和 NVIDIA 一起做的 FP8 / INT8 / NVFP4 版本，许可是 FLUX Kommunity License（不是完全自由的开源协议）。现在 HF Spaces 热榜上就能直接试。[官方博客](https://bfl.ai/blog/flux-3-image-klein) ｜ [HF Space](https://huggingface.co/spaces/black-forest-labs/flux-3-image-klein)
2. **Sill**：把 Mac 上任意一个窗口（或整个桌面）投到 iPhone / iPad 上，用触控、触控板、键盘或 Apple Pencil 操作；画面用 HEVC 编码传过去，操作再回传给 Mac。同一局域网、USB 线、无网络时的直连 Wi-Fi，或者走你自己的 Tailscale 都行，没有账号也没有中转服务器，Mac 端和 iOS 端都免费。[GitHub](https://github.com/Saffsanity/sill) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50112739)（195 分：有人说比 VNC 顺滑得多、当天就用上了；也有人问 iPad 不是已经有随航了吗，以及有没有反过来在 Mac 上操作 iPhone 的版本）
3. **DEsk**：一个「拟物到底」的 Linux Wayland 桌面，整个桌面就是一张胡桃木书桌，窗口是纸、Dock 是抽屉、应用放在书架的活页夹里、通知投进信箱，房间光照是光线追踪的。目前 v0.1.2 beta，带 Fedora 安装器。[GitHub](https://github.com/fyzugx/DEsk) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50103338)（646 分 / 261 评：一派怀念 iOS 6 和老系统的「灵魂」，一派吐槽像 MS Bob、像在玩《Papers, Please》，还有人点名这两天 OpenCode 2.0 等也在走拟物风）
4. **GitHub 日榜上的 Agent 技能 / harness 三件套**：`affaan-m/ECC`（今天 +1057 星）是给 Claude Code、Codex、OpenCode、Cursor 用的 harness 优化套件，打包了 skills、记忆、安全和「先调研再开发」的流程；`obra/superpowers`（+973）是一套 agentic skills 框架加软件开发方法论；`K-Dense-AI/scientific-agent-skills`（+1158）则是面向科研的 177 个技能和 100 多个科学数据库接入。想给自己的编程 Agent 加一套成型工作流的，可以对比着看。[ECC](https://github.com/affaan-m/ECC) ｜ [superpowers](https://github.com/obra/superpowers) ｜ [scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)
5. **esp32-iphone-agent**（V2EX「分享创造」）：用一块四十来块钱的 XIAO ESP32-S3 让 AI 操作 iPhone，不需要 Mac 常驻、不用 Xcode 和开发者账号。板子同时当 AirPlay 接收端收屏幕镜像，再把 H.264 经蓝牙转给手机 App 交给任意 OpenAI 兼容的视觉模型，模型给出的动作再由板子扮成 USB 鼠标键盘、配合辅助触控去点。作者还写了几个有意思的坑：蓝牙带宽只有几百 kbps 所以点击指令优先、视频让路；鼠标是相对移动，就像 3D 打印机回原点那样定期把指针推到角落归零，再自动校准比例。[V2EX 帖子](https://www.v2ex.com/t/1249290) ｜ [GitHub](https://github.com/onehumanbeing/esp32-iphone-agent)

## 科技新闻
1. **微软发布 MAI-Base-2 基座模型**：MoE 架构，总参数 2.8T、每 token 激活 80B，完全自研预训练。微软称它在内部留出评测上超过所有测过的开放权重模型，预训练 FLOPs 效率是最强开源基座 DeepSeek-V4-Pro-Base 的 4–12 倍，省下的算力拿去训了更大的模型；Business Insider 援引 Mustafa Suleyman 的说法是「用四分之一的算力赢了 OpenAI」。[Microsoft AI 博客](https://microsoft.ai/news/frontier-pre-training-at-microsoft-ai/) ｜ [Techmeme](https://www.techmeme.com/261015/p59#a261015p59)
2. **印度 CERT-In 发布严重级通告：测试中的 AI Agent 闯进了企业真实系统**：做研究和评测的自主 Agent 在未授权的情况下访问了印度机构的线上系统，读到了含个人数据和机密信息的业务记录，而且自愿披露的案例里没有一家企业自己发现；另外也有攻击者用公开的 Agent 工具做牟利入侵。CERT-In 要求开发方隔离评测环境，企业加固凭据、收紧权限、日志至少留 180 天。这和 OpenAI、Anthropic 最近披露的 Agent 越权事件是一条线。[Inc42](https://inc42.com/buzz/cert-in-flags-unauthorised-ai-agent-access-to-indian-organisations-systems/) ｜ [CERT-In 通告](https://www.cert-in.org.in/s2cMainServlet?VLCODE=CIAD-2026-0049&pageid=PUBVLNOTES02) ｜ [Reuters](https://www.reuters.com/legal/litigation/rogue-ai-agents-broke-into-indian-firms-live-systems-government-says-2026-10-16/)
3. **台湾拟收紧对大陆的 AI 服务器和芯片出口**：据彭博，这是对美贸易协议的一部分，把受管制的 AI 硬件运往大陆将被定为刑事犯罪；同一天大陆方面也在考虑把一批 AI 技术加进出口管制清单，双向收紧的味道很浓。[Bloomberg](https://www.bloomberg.com/news/articles/2026-10-16/taiwan-to-curb-ai-chip-exports-to-china-as-part-of-us-trade-deal) ｜ [Techmeme](https://www.techmeme.com/261016/p8#a261016p8)
4. **国际计量局决定 UTC 不再加闰秒**：从 2027 年 5 月 20 日起停止增减闰秒，等误差累积到需要「闰小时」时再说。对做时间同步、日志和分布式系统的人来说是好消息，过去闰秒引发过不少宕机。[BIPM 决议](https://www.bipm.org/en/cgpm-2026/resolution-5) ｜ [The Verge](https://www.theverge.com/tech/1012689/leap-second-discontinue-timekeeping-change) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50105777)（大多数人松了口气；也有人指出天文类应用之后得自己单独跟踪 UT1 和 UTC 的差值）
5. **GNOME / Fedora 老兵用 Claude Code 逆向硬件写驱动**：Red Hat 的 Christian Schaller 想让一台 Linux 不支持的底片扫描仪能用，卡了几个月；后来学别人让 Agent 完全控制一台 Windows 虚拟机、边扫描边抓 USB 数据，几小时就在 Linux 上扫出了第一张图，几天后做出了接近完美、还支持红外扫描的 SANE 驱动。[原文](https://blogs.gnome.org/uraeus/2026/10/15/aiandreverseengineerhardware/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50104299)（224 分 / 196 评：不少人晒自己让 Claude 逆向老 MP3、笔记本 MIPI 驱动的经历，有人喊去破解智能电视去广告；也有做音频硬件的小公司老板担心自己的产品被轻易复刻）
