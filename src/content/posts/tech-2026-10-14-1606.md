## 新产品 / 开源
1. **mosh-rs**: a rewrite of mosh in Rust with a wire protocol compatible with the original, adding scrollback and a native Windows client; an existing mosh-server works directly. [GitHub](https://github.com/Arunjay4213/mosh-rs) ｜ [HN discussion](https://news.ycombinator.com/item?id=50080836) (what the comments want most is multiplexing like SSH ControlMaster, but that's a protocol-level limit a compatible implementation can't solve)
> [zh] **mosh-rs**：用 Rust 重写的 mosh，wire 协议与原版兼容，补上了滚动回看和原生 Windows 客户端，现有 mosh-server 可以直接用。[GitHub](https://github.com/Arunjay4213/mosh-rs) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50080836)（评论区最想要的是 SSH ControlMaster 那样的多路复用，不过这是协议层的限制，兼容实现解决不了）
2. **rea** (GitHub Trending): uses an agent for reverse engineering, analyzing from application behavior all the way to the native binary, for people who want to try AI-assisted reverse engineering. [GitHub](https://github.com/morluto/rea)
> [zh] **rea**（GitHub Trending）：用 Agent 做逆向工程，从应用行为一直分析到原生二进制，适合想试 AI 辅助逆向的人。
3. **context-mode** (GitHub Trending): context-window optimization for AI coding agents that puts tool output in a sandbox (the project claims a 98% size reduction), persists session memory, and supports 17 platforms via MCP + hooks. [GitHub](https://github.com/mksglu/context-mode)
> [zh] **context-mode**（GitHub Trending）：给 AI 编程 Agent 做上下文窗口优化，把工具输出放进沙箱（项目自称体积减少 98%）、持久化会话记忆，通过 MCP + hooks 支持 17 个平台。
4. **xtool** (GitHub Trending): a cross-platform Xcode replacement that builds and deploys iOS apps with SwiftPM on Linux, Windows and macOS. [GitHub](https://github.com/xtool-org/xtool)
> [zh] **xtool**（GitHub Trending）：跨平台的 Xcode 替代品，在 Linux、Windows、macOS 上都能用 SwiftPM 构建和部署 iOS 应用。
5. **Pulse Local**: a Mac bookkeeping app whose AI models all run on-device; import any bank's CSV and it works. [Website](https://pulseos.finance) ｜ [HN discussion](https://news.ycombinator.com/item?id=50080275) (comments think manual CSV import will put off many people, and someone asks whether a lighter classifier could be used instead)
> [zh] **Pulse Local**：Mac 记账应用，AI 模型全部在本机运行，导入任意银行的 CSV 就能用。[官网](https://pulseos.finance) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50080275)（评论认为手动导入 CSV 会劝退不少人，也有人问能不能换成更轻量的分类器）
