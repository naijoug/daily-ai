## AI 热点
1. Terence Tao, in a Numberphile interview, criticizes OpenAI's mass release of AI math proofs: the "heroic age" of mathematics is ending and an "industrial age" of big teams is coming, but "nobody at OpenAI is helping us" verify; he has read only about 10 himself, young scholars' starter problems were cleared overnight, and mathematicians have grown reluctant to publish problems (counts vary by source, from 300+ to 700+ proofs). Gary Marcus reposted the clip to criticize OpenAI; AYi's Chinese-language write-up got 7,000+ views this period. https://x.com/iCleanAI/status/2111312791659323896 / https://x.com/AYi_AInotes/status/2111289580833919337 / https://x.com/GaryMarcus/status/2111204167163560055
> [zh] 陶哲轩在 Numberphile 访谈里批评 OpenAI 批量公开 AI 数学证明：数学的"英雄时代"在结束、要进入大团队的"工业时代"，但"OpenAI 没有人在帮我们"核验，他自己只看了约 10 篇，年轻学者的入门课题一夜被清空，数学家开始不愿公开问题（篇数各家说法不一，300 多到 700 多份）。Gary Marcus 转发片段批 OpenAI，中文区 AYi 的解读本时段 7000+ 浏览。
2. Meta Muse Spark Open weights (released 10/15; this period's discussion centers on deployment and license): an 816B-total, 42B-active MoE with 1M context, natively multimodal, aimed at coding and agents; optimized with Apple via MLX and able to run locally on two M5 Ultra Mac Studios. The license requires the label "Built with Muse Spark Open", companies with over $20M annual revenue need a separate agreement to offer it as a model API, and distilled models count as derivatives; citing Meta's own model card, its AA intelligence index is 39, behind GLM 5.3 (45) and Kimi K3 (44). https://x.com/TechRepublic/status/2111116195357188255 / https://x.com/supdeck1/status/2111163204604772436 / https://x.com/BrianUvena/status/2111100239708905568
> [zh] Meta Muse Spark Open 开放权重（10/15 发布，本时段讨论集中在部署和许可）：816B 总参、42B 激活的 MoE，1M 上下文，原生多模态，主打编程和 agent；和 Apple 合作用 MLX 优化，可在两台 M5 Ultra Mac Studio 上本地跑。许可要求标注 "Built with Muse Spark Open"，年营收超 2000 万美元的公司拿它做模型 API 要另签协议，蒸馏出的模型也算衍生品；有人引用 Meta 自己的模型卡，AA 智能指数 39，落后 GLM 5.3（45）和 Kimi K3（44）。
3. ChatGPT's GPT-6 Pro (Astra-powered) adds parallel multi-agent: one task is split among several agents working at once, you can see each agent's progress in the conversation and open a finished subtask to see what it did, with faster and better responses and tool calls; available to Pro/Business/Enterprise, not Plus in Chat. OpenAI hasn't said the agent cap, whether context is shared, or how quota is counted. https://help.openai.com/en/articles/6825453-chatgpt-release-notes / https://x.com/i/trending/2111190989901631679
> [zh] ChatGPT 的 GPT-6 Pro（Astra 驱动）加入并行多 agent：一个任务拆给多个 agent 同时做，对话里能看每个 agent 进度、打开完成的子任务看它做了什么，响应和工具调用也更快更好；面向 Pro/Business/Enterprise，Plus 在 Chat 里没有。OpenAI 没说 agent 上限、是否共享上下文、怎么算额度。
4. 5. Gemini 4 Argon comes to AI Studio: Logan Kilpatrick told a user that paid Pro users can use Argon in AI Studio starting today. https://x.com/OfficialLoganK/status/2111312574906331504
> [zh] Gemini 4 Argon 进 AI Studio：Logan Kilpatrick 回复网友，付费 Pro 用户从今天起能在 AI Studio 用 Argon。

## 有趣用法和干货
1. Thorsten Ball (Amp), "Why are we still using PRs?" (1300+ likes, 1350 bookmarks, 315 replies, echoed by omarsar0 this period): reviews can be done several times each by Opus 5.5/Fable/Astra, the agent has already run the full tests and recorded an end-to-end demo before pushing, so running CI again on a PR is redundant. Amp's actual flow: push straight to main, Buildkite runs tests and builds images, GitHub Actions does infrastructure security checks and triggers deploy, and a failed check blocks deploy and pings the committer in Slack. https://x.com/thorstenball/status/2111130129355481240 / https://x.com/thorstenball/status/2111115720637722945 / https://x.com/omarsar0/status/2111276560095576563
> [zh] Thorsten Ball（Amp）《为什么还在用 PR？》（1300+ 赞、1350 收藏、315 回复，omarsar0 本时段附和）：审查可以让 Opus 5.5/Fable/Astra 各查几遍，agent push 前已跑全量测试并录端到端演示，PR 再跑一遍 CI 是重复。Amp 的实际流程：直接 push main，Buildkite 跑测试和构建镜像，GitHub Actions 做基础设施安全检查并触发部署，检查失败就阻断部署、在 Slack ping 提交者。
2. Perplexity open-sources decision models Decider v1.2 (27B) and Flash v1.2 (4B): they don't write text; give a situation and some questions and they return yes/no, choices or scores with probabilities; on OpenRouter and Vercel AI Gateway, Flash costs about 1 cent per million tokens. Good for inserting cheap routing, judging and scoring at each agent step. https://x.com/OpenRouter/status/2111200007437402243 / https://x.com/vercel_dev/status/2111211692030152951 / https://x.com/jbish1572/status/2111275552455946471
> [zh] Perplexity 开源决策模型 Decider v1.2（27B）和 Flash v1.2（4B）：不写文本，给情境和几个问题，返回带概率的是/否、选项或分数；已上 OpenRouter 和 Vercel AI Gateway，Flash 约 1 美分/百万 token。适合在 agent 每一步插便宜的路由、判定、打分。
3. Ben Tossell 的 agent 工作法（Mai Yang 配双语字幕+时间轴）：指令里写"提问时只回答、不许顺手改东西"；流程是探索→原型→打磨→上线→自动化重复部分；每次让 agent 出三个版本再挑；agent 不懂就从文字升级到语音、截图、录屏、在图上画。https://x.com/MaiYangAI/status/2111295287880831211
> [en] Ben Tossell's agent workflow (Mai Yang added bilingual subtitles and timestamps): write "when I ask a question, only answer, don't change things on the side" in the instructions; the process is explore → prototype → polish → ship → automate the repetitive parts; each time have the agent produce three versions and pick one; when the agent doesn't understand, escalate from text to voice, screenshots, screen recordings and drawing on images.

> [en] 向阳乔木 open-sources the Obsidian plugin Qiaomu Publish: from one note, tune WeChat official-account layout, fonts and cover and send to the drafts box, and connect to X, Zhihu and Xiaohongshu (can generate images); search Qiaomu Publish in the community plugin market; the author suggests a manual review as the last step since fully automatic posting gets rate-limited.
