## 有趣用法和干货
1. Turn agent failures into regression tests with "session replay" (Paul Iusztin, author of the LLM Engineer's Handbook): while using Claude Code to write the eval layer for his own coding agent Decode, a cold-start 503 from the Modal endpoint made the agent not wait but dig out Gemini API keys in memory and swap between them, burning $40 over 20 benchmark runs (expected $4–5). His fix is to record sessions and cache tool returns with Kitaru, replay with the original context after fixing and compare results, without re-calling APIs or databases that change external state; the flow is record, review, categorize failures, fix, replay, compare. Two lessons engineers can use directly: don't leave extra keys in the agent's environment, and run historical failures before changing prompts or models. https://x.com/pauliusztin_/status/2111434556779683852 / https://x.com/pauliusztin_/status/2111374154364600573
> [zh] 用"会话回放"把 agent 的失败变成回归测试（Paul Iusztin，《LLM Engineer's Handbook》作者）：他用 Claude Code 给自研编码 agent Decode 写评测层时，Modal 接口冷启动返回 503，agent 没等，而是翻出内存里的 Gemini API key 换着用，跑 20 个基准测试烧了 40 美元（预期 4–5 美元）。他的做法是用 Kitaru 录下会话并缓存工具返回，修完后按原上下文重放、对比结果，而且不会再次调用会改外部状态的 API 或数据库；流程是录制、审查、归类失败、修复、重放、对比。对工程师来说，两个教训都能直接用：给 agent 的环境里别放多余的 key，修 prompt 或换模型前先拿历史失败跑一遍。
2. Run 23 checks with Claude Code before you start taking money (Vox): the checklist includes secrets only on the server and searched in frontend and git history, every endpoint validating login and permissions server-side with RLS on, payment webhooks signature-verified and counted once on duplicate callbacks, amounts stored as integers in the smallest currency unit, double-clicking submit creating only one order, migrations all with rollback SQL tested both ways on a copy of production data, Supabase returning at most 1000 rows by default so nothing is silently truncated, timestamptz for time, and so on. Usage: send the whole checklist to Claude Code and add: split into 5 subagents (design and speed, security, payments, data, post-launch) that only check and don't change, mark each item pass or fail with the problem file, mark dashboard-only items "needs my confirmation", test backups and payments only in a test environment, and give a table first and wait for confirmation before fixing. https://x.com/Voxyz_ai/status/2111442102756463077
> [zh] 上线收钱前让 Claude Code 跑一遍 23 项检查（Vox）：清单包括密钥只在服务端并搜过前端和 git 历史、每个接口在服务端校验登录和权限并开 RLS、支付 webhook 验签且重复回调只记一次、金额用最小货币单位的整数存、双击提交只生成一个订单、迁移都写好回滚 SQL 并在生产数据副本上双向跑过、Supabase 默认最多返回 1000 行别被悄悄截断、时间用 timestamptz 等。用法是把整份清单发给 Claude Code，末尾加一句：分给 5 个子 agent（设计与速度、安全、支付、数据、上线后）只查不改，每项标通过或失败和问题文件，仪表盘里才能看的项标"需要我确认"，备份和支付只在测试环境测，先给表格、等确认再修。
3. Share one memory across multiple coding agents: the open-source akitaonrails/ai-memory lets you switch from Claude Code to Codex in the same directory halfway through without re-explaining the architecture, failed approaches and open questions; supports 20+ agents, memory is plain markdown kept in git that you can edit directly, no LLM calls or API keys by default, and it can run on one machine or be self-hosted for a team. Worth a try if you switch tools back and forth when quotas run out. https://x.com/AkitaOnRails/status/2101451863145238819 / https://x.com/Godgun522/status/2111444750138232984
> [zh] 多个编码 agent 共用一份记忆：开源的 akitaonrails/ai-memory 让你在 Claude Code 里做到一半，换 Codex 在同一目录接着做，不用重讲架构、失败过的方案和未决问题；支持二十多种 agent，记忆是放在 git 里的普通 markdown，可以直接改，默认不调大模型、不要 API key，可单机跑也可自托管给团队共用。额度用完来回切工具的人可以试。
4. 什么样的 skill 才值得装（铁锤人）：好 skill 要容易触发、正文短（skill 吃上下文，上下文越满越降智，所以要清楚模型已经会什么、只写它不会的）、结构上防止跳步和偷懒（比如让查 10 条新闻结果只查了 2 条）。他的结论是大部分 skill 达不到，与其装上百个，不如禁用掉、直接贴指令。https://x.com/lxfater/status/2111423678256955816
> [en] What kind of skill is worth installing (铁锤人): a good skill is easy to trigger, short (skills eat context, and the fuller the context the dumber the model, so know what the model already knows and write only what it doesn't), and structured to prevent skipping steps and laziness (e.g. asked to check 10 news items but checked only 2). His conclusion: most skills don't meet the bar, so rather than install hundreds, disable them and just paste the instructions.
