## 新产品 / 开源
1. **Llmspeed（Show HN）**：买显卡或 Mac 之前，先在浏览器里「体感」一下本地模型的出字速度。选硬件（RTX 3090/5090、Strix Halo、Mac Studio M5 Ultra、DGX Spark 等）和模型（Qwen 3.8 27B、DeepSeek V4 Flash 等），它按估算的 token/s 模拟出字速度；数据来自 r/LocalLLaMA、localscore.ai 等社区实测，缺的组合按相近配置或规格推算，代码开源。[官网](https://llmspeed.dev/) ｜ [GitHub](https://github.com/nicorobinreal/llmspeed) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50127979)（133 分：有人说自己的 M2 Ultra 比页面上 M3 Ultra 的数还快一倍，估算准不准是关键；做 Agent 编程的人提醒预填充（prefill）和并发比输出速度更重要；还有人建议直接租台云 GPU 试几分钟，花不到 0.5 美元）
2. **Orca**：一个管理「一群编程 Agent」的桌面应用，Codex、Claude Code、OpenCode、Pi 可以并排跑，每个在独立的 git worktree 里；可以把同一个提示分给五个 Agent，比较结果后合并最好的那个。还带 WebGL 终端分屏、点选网页元素把 HTML/CSS 和截图塞进提示的设计模式，以及能在手机上看进度、发追问的配套 App。用你自己的订阅，MIT 许可，今天 GitHub Trending 单日 1100+ 星。[GitHub](https://github.com/stablyai/orca) ｜ [官网](https://onorca.dev)
3. **ai-job-search**：一位地球物理学家被裁后用 Claude Code 搭的求职流水线，`/scrape` 搜职位、`/apply` 评估匹配度并起草定制的 LaTeX 简历和求职信（另有一个审稿 Agent 把关）、`/interview` 准备面试。作者说自己投了 69 份、拿到 20 个一面，最后在 2026 年 6 月入职 AI 工程师。职位抓取部分针对丹麦招聘站，但流程本身和语言、国家无关，可以换成自己的招聘站，MIT 许可，今天 Trending 单日约 1400 星。[GitHub](https://github.com/MadsLorentzen/ai-job-search)
4. **Google 官方 android/skills**：Android 团队维护的一套 Agent Skills（标准 SKILL.md 格式），按 developer.android.com 的最佳实践写，刻意只覆盖评测显示大模型容易做错的场景（比如 R8 混淆分析、Wear OS Compose），不重复写基础 Compose 这类模型已经会的东西。可以用 Android CLI 的 `android skills add --all` 一次装进本机检测到的各个 Agent，也能当 Claude Code 插件装，Apache 2.0。[GitHub](https://github.com/android/skills) ｜ [官方文档](https://developer.android.com/tools/agents/android-skills)

## 科技新闻
1. **越来越多网站把 AI Agent 拒之门外**：The Verge 汇总了最近 Meta Muse、xAI Grok、OpenAI Dots、Instinct 等 Agent 用户遇到的封锁：Yelp 只放行付费买数据授权的 Agent，达美航空不让 Agent 代订机票，还有一些服务以安全为由禁止 Agent 登录账号；即便没明确禁止，Cloudflare 这类反爬系统也经常把 Agent 当机器人拦下。Meta 选择和沃尔玛、Gap、百思买等签合作让 Muse 购物。对做 Agent 产品的人来说，「能上哪些网站」正在变成实际的能力上限。[The Verge](https://www.theverge.com/ai-artificial-intelligence/1013195/ai-agents-blocked-web)
2. **Anthropic 为买 Google TPU 借 600 亿美元，给黑石开出 10% 以上的利率**：据 FT，黑石拟认购其中 90 亿美元，较高的借贷成本让 Anthropic 想拿到投资级评级更难。Ed Zitron 等人批评这笔交易风险很大。[FT](https://www.ft.com/content/cb4034e1-475f-40b9-a5f9-256e91aacb89) ｜ [Reuters](https://www.reuters.com/business/anthropic-offers-blackstone-double-digit-yield-chip-financing-deal-ft-reports-2026-10-17/) ｜ [Techmeme](https://www.techmeme.com/261016/p29#a261016p29)
3. **Meta 承认智能眼镜会在没唤醒的情况下录音**：有用户发现在没说「Hey Meta」、相关设置也关着的情况下，Ray-Ban Meta 眼镜的指示灯亮起并录下、转写了对话，而且在三副二代、三代眼镜上都复现了，评论区也有人遇到过；Meta 已确认并称已修复。[Mashable](https://mashable.com/tech/meta-confirms-smart-glasses-recording-without-being-activated) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50126241)（评论基本是「毫不意外」，有人认为 Meta 的信任问题会连累整个智能眼镜品类）
4. **Mercor：美国 90% 的工作时长落在 AI 基准几乎没测过的任务上**：Mercor 把现有 AI 基准的题目映射到美国劳工部 O*NET 的职业和任务上，发现覆盖很不均匀，偏向工资总额大的职业，比如律师的任务被大量覆盖，但同样容易被 AI 影响的法律秘书、书记员几乎没人测，长尾的中等收入知识工作基本是空白。这条是本时段开始前上的 HN，之前没写过。[原文](https://www.mercor.com/research/labor-index/benchmark-map/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50121179)（541 分：高赞观点是人类大部分工作缺少训练和 Agent 需要的快速反馈闭环，所以生产率提升更像每年 2% 的老节奏；也有工程师自嘲 80% 的时间在调和各方意见）
5. **Claude Haiku 4.5 将从 Claude App 的模型列表下线**：10 月 29 日起，Free、Pro、Max 用户的网页、桌面、移动端及 Cowork、Design 里不再能选 Haiku 4.5，已选的会自动切到 Haiku 5.5，旧对话保留；Claude Code、Team/Enterprise 和 API 不受影响。[IT之家](https://www.ithome.com/1/014/312.htm)
