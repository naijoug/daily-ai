## 新产品
1. **1Password for Agents：让 AI agent 登录账号却看不到密码**：agent 到了登录页，先用自己的数字密钥向 1Password 证明身份；你在自己设备上看到它要哪个账号、为什么要，批准后由 1Password 直接把凭据填进表单，密码始终不交给 agent 或模型，流程类似二次验证。首批对接 Meta Muse、Claude Duet、ChatGPT Work 和 Dots、Grok Bot、Town，Browserbase、Browser Use、Perplexity、Ramp 等也在接入。想让个人 agent 代办需要登录的事、又不想把密码贴进对话的，可以关注这套授权方式。[1Password 新闻稿](https://1password.com/press/2026/october/1password-for-agents-trust-layer-personal-ai-agents) ｜ [The Verge](https://www.theverge.com/ai-artificial-intelligence/1016399/1password-ai-agent-password-sign-in)
2. **Claude for Google Workspace：Claude 进驻 Docs、Sheets、Slides（公测）**：所有付费版可用，以侧边栏插件的形式出现，能读当前文件和你选中的内容并直接改：Docs 里就地改句子，大改动给出可逐条应用的建议卡片；Sheets 里写公式、做透视表和原生图表，清洗数据时还能把区域拉进 Python 算完再写回；Slides 按现有版式生成新页，并检查元素重叠和文字溢出。默认「改之前先问」，也可切到「全部接受」。另外新出了 Docs、Sheets、Slides 连接器，从 Claude 对话里就能新建和编辑 Google 文件，权限与你的 Google 共享权限一致。[Claude 官方](https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50190357)（有人惊讶 Google 会允许竞争对手这样深度嵌进自家产品）
3. **OpenAI 官方 CLI 开源**：用 Go 写的 OpenAI REST API 命令行工具，`brew install openai/tools/openai` 或 `go install` 安装，命令按资源组织，比如 `openai responses create --input ... --model ...`，管理员 key 还能直接查组织用量；`openai help` 不用联网也不用 key，图片生成带交互式选择器。适合在脚本、CI 里调 API，也方便交给 agent 调用。[GitHub](https://github.com/openai/openai-cli) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50191507)（评论在问它和 Codex 怎么分工，也有人吐槽 README 没讲清楚这工具是干嘛的）
4. **Resend Inboxes：给 agent 用的共享邮箱**：开发者邮件服务 Resend 推出收件箱 API，一次调用就能给应用或每个 agent 开一个专属地址，按会话拉取和回复邮件；现有 agent 可以通过 MCP 或 skill 接入，还能用自然语言让 agent 分拣、打标签、起草回复，由 webhook 触发，团队成员可以分配和接手会话。今天在 Product Hunt 上线。[Resend](https://resend.com/inboxes) ｜ [Product Hunt](https://www.producthunt.com/products/resend)
5. **Carbon-X：Hugging Face 开源的 14B DNA + 自然语言模型**：基于 Qwen3-14B，在 302B token 的 DNA、生物文本和英文混合数据上继续训练，再做 SFT 和 GRPO。DNA 按 6 碱基一个 token 编码，和文字共用一个解码器，直接在对话里贴序列提问即可，比如判断突变是良性还是致病。五项 DNA 基准平均 66.7%，接近 GPT-6.1 Sol 的 67.5%，单题推理成本约为其 1/1800；单张 80GB GPU 就能用 vLLM 跑，Apache 2.0 协议，还附带给 Claude Code、Codex 用的 skill。[Hugging Face 模型页](https://huggingface.co/HuggingFaceBio/Carbon-X) ｜ [Techmeme](https://www.techmeme.com/261022/p15#a261022p15)
6. **WorldTUI：一个 360M 小模型「假装」自己是终端**：作者用 Docker 里录下的 33.6 万段真实终端会话微调 Qwen2.5-Coder-0.5B，背后没有 shell 也没有文件系统，每按一次键，模型就预测屏幕要怎么变，能跑 vim、tmux、贪吃蛇，还大致记得几条命令前写过的文件。几个关键技巧：用 COPY 操作表示滚屏，按行并行解码再顺序校验（大画面 p95 延迟从 6.7 秒降到 0.87 秒），以及让模型学着修正自己之前的错误。裁掉词表后量化成 int4 只有 208MB，可以用 WebGPU 在浏览器里试。[作者博客](https://simedw.com/2026/10/21/world-model-terminal/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50190363)（337 分。有人联想到微软那个用模型模拟 Quake II 的项目）

1. **亚马逊：PHP2Shell 在 10 月 17 日、官方披露前四天就已被利用**：亚马逊威胁情报的 MadPot 蜜罐在 10/17 就记录到来自匿名网络的利用尝试，10/21 解禁前还出现了多组不同来源的 payload；补丁发布后几小时内又冒出新的 PoC，现在已是大规模在野利用。CISO CJ Moses 的建议是：调查时间线从 10/17 开始算，不要从公告日算；面向公网的严重漏洞，修补时限要按小时计；暂时不能升级的，可以考虑屏蔽 multipart 上传，并排查表单里带 `PHP_SESSION_UPLOAD_PROGRESS` 的 POST 请求。另一边，之前在 HN 提前透露漏洞的网友发帖道歉，说当时不知道还有禁运期。[AWS 安全博客](https://aws.amazon.com/blogs/security/amazon-threat-intelligence-identifies-php2shell-exploitation-prior-to-public-disclosure-in-madpot/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50194070)（有人吐槽 Amazon Linux 的 PHP 包在补丁发布 18 小时后才更新） ｜ [HN：泄露者道歉](https://news.ycombinator.com/item?id=50193416)
2. **Linux 内核几个高危漏洞被误发到公开邮件列表**：Trend Micro 的 ZDI 把一批漏洞报告发到了公开的 LKML，没有走私密的安全列表，Greg Kroah-Hartman 逐条回复询问。其中 SMB Direct 整数下溢导致远程代码执行、KSMBD 竞态导致远程代码执行这两个都是 CVSS 9.0，另有 skb_zerocopy、vmwgfx 越界写的本地提权和 NVMET 信息泄露。目前主线还没有修复，部分补丁还在测试或排在 -next 分支里。开着内核 ksmbd 的机器建议先关掉，等补丁。[Phoronix](https://www.phoronix.com/news/LKML-New-Trend-Vulnerabilities) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50193804)
3. **Oracle 发布 Java SE 安全警报：JSSE 漏洞 CVSS 9.1，无需认证即可远程利用**：CVE-2026-91403 出在 Java 安全套接字扩展（JSSE）里，攻击复杂度低，不需要权限也不需要用户交互，通过调用相关 API 的 Web 服务就能触发，会严重影响机密性和完整性。受影响的有 Java SE 8u511、11.0.33、17.0.21、21.0.13、25.0.5、27.0.1，GraalVM for JDK 17.0.21 和 21.0.13，以及 GraalVM Enterprise 21.3.20。跑 Java 服务的团队要尽快排期升级。[IT之家](https://www.ithome.com/1/016/697.htm)
4. **eMudhra 证书事件后续：命令行工具和 macOS 自带的 curl、git 也要处理**：发现者做了个检查页 we-have-a-problem.com，用 `curl https://dv-g3b-emudhra.we-have-a-problem.com/` 报证书错误，就说明你的客户端已经不信任这批 CA 了。页面列出已修复的版本：Claude Code 2.1.303、uv 0.13.4、pip 26.2.2、Node.js 22.23.4、24.22.1、26.12.1、Docker Desktop 4.96.2、Deno 2.9.8 等，Bun 还没修。macOS 系统虽然已经拦截，但自带的 curl、git、python3 用的是 `/etc/ssl/cert.pem`，不检查吊销，需要按页面上的命令手动剔除受影响的根证书。该漏洞已编号 CVE-2026-111943，eMudhra 也宣布退出全球 SSL/TLS 证书业务。[检查与修复指南](https://emudhra.we-have-a-problem.com/) ｜ [HN：CVE-2026-111943](https://news.ycombinator.com/item?id=50192900) ｜ [HN：eMudhra 退出 TLS 业务](https://news.ycombinator.com/item?id=50194909)
5. **333 个 Tor 出口节点被劫持，专门截 SSH 和明文邮件**：攻击者先用一个被重复使用的密码进了 Tor 的管理服务器，装上 Linux 后门 Ebury，再扩散到其他服务器。10 月 2 日到 5 日之间，被控制的出口节点把 22 端口的 SSH 流量转到 12 台拦截服务器上，用户如果无视「主机密钥已变化」的警告继续输入密码，密码就会被偷走，服务器还会被植入 Ebury；同时这些节点屏蔽加密邮件端口，逼客户端降级成明文。教训很朴素：SSH 关掉密码登录、只用密钥，邮箱只接受加密连接。[Ars Technica](https://arstechnica.com/information-technology/2026/10/300-tor-exit-nodes-hijacked-to-intercept-ssh-traffic-and-retrieve-plaintext-email/)
