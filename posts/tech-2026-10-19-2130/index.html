模型Agent编程工具开源

新产品 / 开源

  1. Superlite：给 Claude Code 用的「交给它就走开」插件：作者很喜欢 superpowers，但嫌它每个功能要停下来让人批准 8–12 次，还一次只跑一个实现 agent。superlite 改成只问一批问题、批准一次，把计划写成任务图，互不冲突的任务并行跑：Opus 只负责规划和派活（用 hook 禁止它改代码），Sonnet 写大部分任务，Haiku 做小而明确的活，最后由新开的 Opus 只挑问题、不动手；它原本会问你的选择都记成「裁决」，回来一看就知道先检查哪些。作者的基准是一个用 177 个隐藏测试打分的项目，最新一次 16.1 分钟全过，最多 18 个 agent 同时干活，superpowers 原版 3 次平均要 33.6 分钟。不会自动 push 或 merge。博客 ｜ GitHub ｜ HN 讨论（114 分。好几个人说 superpowers 几个月前有用，现在 Opus 5.5 自己就会写 spec、默认你同意然后直接做完，这类插件没那么必要了；也有人追问并行会多花多少 token、多个 agent 会不会改到彼此的文件）
  2. Mistral 发布 Timestral：第一个时间序列基础模型系列：有 4 个尺寸，从 5M 到 209M 参数，最大的那个在 GIFT-Eval、TIME、fev-bench 三个主要公开榜上都排第一，参数只有之前最好模型的三分之二。能做概率预测和多变量预测，支持只有历史值的协变量和提前已知的未来协变量，在 CPU 上也能跑；零样本直接用，也能通过 Mistral Forge 用自己的数据微调。做容量规划、监控指标预测的可以试试。Mistral ｜ HN 讨论（有人感慨五年前要花几个月做的预测模型现在几分钟就能上线；也有人质疑时间序列和文本本质不同，「基础模型」的实际用处有限，还有人吐槽图表把 0.03 的提升画成了 5 倍差距，问它和 Nixtla TimeGPT 比如何）
  3. 把 AI 腔训掉的 Qwen3-4B（Show HN）：作者先写了个「AI 腔」检测器，按破折号、「不是 X 而是 Y」、三连排比、自问自答、「delve」这类词加权计分，人类写作通常低于 15，原版 Qwen3-4B 平均 121。他用蒸馏加 LoRA，再配一个只改 4 个神经元的补丁，三轮下来做到 12.5 分，任务完成度保持在 80%（中间一轮分数更低，但模型开始不表态、编造研究，所以又改了回来）。文章把每轮踩的坑都写清楚了，比结果本身更有意思。Q4_K_M 量化版 2.5 GB，Ollama 或 llama.cpp 都能直接跑。文章 ｜ Hugging Face ｜ HN 讨论
  4. STROT：只在编译时用一次大模型，之后在本地做分类和路由（Show HN）：你写一句意图（比如「把工单分到正确的流程」）和候选动作，大模型只在第一次编译时用来合成标注数据、输入映射和处理逻辑；之后每条记录都交给一个 144M、跑在 CPU 上的本地小模型决策，作者说每条约 60 ms、没有额外费用，输出是带置信度的类型化 JSON，没把握时会弃权而不是乱猜。MIT 开源，pip install strot-ai。GitHub ｜ HN 讨论（有人很认同「推理一次、之后一直复用结果」的思路；也有人反问，直接让大模型写个程序不就行了，还有人说 README 没讲清楚具体怎么做）
  5. headroom：在内容进模型之前先压缩：今天 GitHub Trending 新冒出来的。它在本地按内容类型挑压缩器，JSON、源码（基于 AST）和普通文本各有一套，还会标出会破坏 KV 缓存前缀的易变内容；原文存在本地，模型需要时可以调 headroom_retrieve 取回全文。README 说能给 coding agent 省约 20% token，JSON 能省 60–95%。可以当库、本地代理或 MCP server 用，headroom wrap claude 就能直接包住 Claude Code。GitHub
  6. Harness Engineering 101：从零讲怎么搭一个 agent：16 章的开源小书。核心观点是 LLM API 没有状态，所谓 harness 就是负责构建、维护、保护那个消息数组的程序，agent 的各种设计都是给这个循环打的补丁，每个补丁都对应某个具体出过的问题。每章都按「出了什么问题、最小的补丁、补丁的代价」来写，配一个约 300 行的纯 Python 玩具 agent，从工具调用、缓存为什么要讲顺序，讲到上下文预算。GitHub ｜ 在线阅读 ｜ HN 讨论（评论区不太买账，有人嫌标题拟人化，有人读到「Load-Bearing」这个词就判定是 AI 写的）

  1. Linux 7.3 正式发布，各项数字都创了纪录：这个版本有 18,765 个非合并提交，来自 3,021 位开发者，其中 807 人是第一次给内核提交代码。主要变化有 binfmt_misc 扩展、大型系统上的组调度优化、一个让所有操作都失败的新文件系统 failfs、新的 fchroot() 系统调用、BPF 的全局 per-CPU 数据、sched_ext 子调度器完工、虚拟机工作集跟踪、ntfs3 支持备用数据流，以及一大批 SMB 服务端改进。LWN ｜ HN 讨论（370 分。有评论贴出内核 SMB 服务端新增了可选的 Apple Time Machine 支持；有人感叹 Apple Silicon 进展很快，已经支持 M3 Pro、Max、Ultra；也有人猜新人数暴涨和 AI 辅助写补丁有关）
  2. MiniMax M3.1 Flash 上线：线上推理快了近 3 倍，价格降了 70%：之前匿名处理了 200T 多 token 的「Space Bunny」就是它的早期版本。官方成绩有 DeepSWE v1.1 73.7%、OSWorld V2 61.7 分、Agents’ Last Exam 29.6 分（后两项是国产模型第一），CyberGym 82%。DeepSeek V4.1 Flash 刚把价格打下来，国产 Flash 档的价格战还在继续。LinuxDo 上已经有人问它为什么热度不高，并提到 opencode 免费提供它。IT之家 ｜ LinuxDo
  3. agent 成了攻击工具，也被当成内鬼来防：路透社报道，一名安全研究员观察到，一名说中文的黑客在两周多里用 AI agent 攻击了 1,200 多个网站，攻破 100 多家机构，包括 Deere 和 SharkNinja，总花费只有约 5,000 美元。同一天，微软在 365 E7 套件里推出新的安全工具，以及一套叫 Project Perception 的系统，把 AI agent 当成潜在的内部威胁，持续给它们做风险评估。Techmeme（路透社） ｜ Techmeme（GeekWire）
  4. 把 Claude 一个人丢在虚拟荒岛上，它开始「玩」了：MIT CSAIL 的研究者把多份 Claude Opus 4.7（起名 Eko）单独放在一个类似 Roblox 的岛上 30 小时，不给任何任务。它们自己定目标，比如爬最高点、看石块能扔多高；用石块拼出心形、自己的名字和仙后座星图；还发明了篮球和「地板是岩浆」这类游戏。有一次它连续接住 50 次抛物，又觉得太快不算数，改了更严的规则重来。关键结果是，玩过 30 小时的 agent 之后做具体任务比新开的副本强，删掉它们记忆文件里的内容，表现就会下降。论文还没经过同行评审，伯克利的学者提醒，也可能只是模型在按提示模仿人。MIT Technology Review
  5. vibe coding 正在改变合成器圈子：The Verge 发现，过去一个多月，大量硬件合成器、采样器、groovebox 出了玩家自制的固件，几乎都是靠 Claude 这类工具写出来的。以前给 Korg Volca 加个力度感应要花几周到几个月，现在业余玩家几天就能把便宜的 Temu 合成器改成功能齐全的 groovebox。Elektron 的几款机器、Roland SP-404 MKII、Ableton Push 3 和 Move、Akai MPC、Novation Circuit、Arturia MicroFreak，甚至 14 年前的 Zoom Multistomp 都有了新固件，带头的是一台 70 美元的 DX-7 仿品 M-Vave FM-1。这是「AI 让小众硬件改装变便宜」的一个具体例子。The Verge

  1. V2EX：koto，在不同 Agent Harness 之间复制、迁移会话：想从 Codex 换到 pi 这类工具，又不想丢掉已经积累的上下文时，可以直接跟 agent 说「用 koto 复制当前会话到 pi」，它会调 koto CLI 完成复制，并告诉你新会话怎么打开。另有桌面 App，可以浏览各家 harness 的会话、复制任意轮次，用会话树看分叉，还能逐行比较同一任务几条会话的差别。支持 macOS、Windows、Linux，完全开源。V2EX ｜ GitHub
  2. LinuxDo：Context Lens，给 Codex 桌面端加了个上下文用量面板：鼠标悬停在已完成回复旁的饼图上，就能看到这一轮上下文用了多少、还剩多少，以及消息、工具调用和返回、Skills、记忆指令各占多少，历史回复也能回看当时的用量。插件只读本地的 Codex 会话日志，不需要 API Key。目前只支持 macOS 上的 Codex 和 ChatGPT 桌面端，安装包没签名。MIT 开源。LinuxDo ｜ GitHub
  3. V2EX：open-doubao-phone，开源版「豆包手机」：基于 AOSP 和 Android 17 的系统，加上操作助手 App 和桌面端（下发任务、拉日志、配 key），一句话让 agent 操作手机里的应用，支持长期记忆。作者说豆包手机一二代对非字节系应用有权限限制，他的版本把助手当成系统的一等公民，优先走无障碍接口，不行再退回视觉模型，模型可以自己配，自带谷歌三件套。和今天中午 X 汇总里写的阿里 OpenGCUA 是同一个方向，一个在电脑上，一个在手机上。V2EX ｜ GitHub
