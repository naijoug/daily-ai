## 有趣用法和干货
1. Shopify 的「前沿模型当主脑、自训开源小模型当专家」（meng shao 整理 GTC Berlin 演讲）：Sidekick 里 GraphQL 子 agent 每输出 1 个 token 要读约 40 个 token，于是交给后训练过的 Nemotron 3.5 Lightning（30B 总参、3B 激活）。做法是先用 LLM 评审对齐专家打分，再把前沿 agent 调到最好当基线，每晚把生产里的失败对话交给前沿模型只给提示、重跑通过后匿名化进训练集。6 轮后评审分 74.5 超过前沿模型的 73，中位响应 0.87 秒对 6.5 秒，成本降约 90%。上下文很重、输出很少的子任务都可以照这个思路拆。https://x.com/shao__meng/status/2112889195178181033 ｜ https://x.com/Drewch/status/2112848318296629342
2. 「Harness 已死？」Cursor/Grok Bot Harness 负责人 Jediah Katz 在 AIE NYC 的演讲（24 小时 10 万播放）：帮模型写好代码的那部分补丁正在被模型吸收（UC Berkeley 测试 7 个前沿模型配不同 harness，SWE-bench Lite 差别不显著），但开拓新任务类型、云端长时运行、权限与安全、缓存命中和 token 效率这几块不会消失。对自己写 agent 的人来说，结论是把 harness 设计得容易上线和下线功能，重点投入在成本和安全。https://x.com/shao__meng/status/2112856210945028483 ｜ https://x.com/aiDotEngineer/status/2112665680348660147
3. MIT 6.S950「Agency with AI」第 5 讲 The Harness 讲义：用一个约 300 行 Python、两个工具的教学 agent 讲清 ReAct 循环，并把常见做法归到几条老系统原则上——精简 AGENTS.md、按需加载 skill、大输入放文件对应「工作集」；会拦截的 hooks 和 deny 规则对应「引用监控器」；权限隔离对应最小权限。还提醒 `/context` 显示的不等于真实请求、子 agent 汇报是有损摘要。适合当团队 agent 规范的理论底稿。https://agencyai.mit.edu/w5/ ｜ https://x.com/shao__meng/status/2112821429121204275
4. 让 Claude Code 一次给出 3 套设计方向（Vox）：开源的 design-taste 有 24 个 skill 和 10 个风格包。原帖给了一段可直接复制的提示词：克隆仓库但不运行安装脚本，只把核心 skill 和风格包复制进项目的 skills 目录，让它读需求后选 3 个最合适的风格，各做一个单文件 HTML 首屏（hero-1/2/3.html）并排对比，选定后再用那个风格做整页并跑上线前检查。解决 agent 生成页面千篇一律的问题。https://x.com/Voxyz_ai/status/2112876561330520549
