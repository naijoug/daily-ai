## 有趣用法和干货
1. Claude 官方安全插件三行跑全仓扫描（Vox）：先 /model 切到 Opus 5.5，然后 `/plugin install claude-security@claude-plugins-official`、`/reload-plugins`、`/claude-security scan the whole repo at high`。它派一组 agent 扫全仓，每个发现再交给 3 个专门"挑刺"的 agent，至少两个同意才写进报告；跑完再执行一次选 Suggest patches，每条发现生成补丁文件由你挑着应用。大仓库要几十分钟到几小时、会耗额度；装不上先 `/plugin marketplace add anthropics/claude-plugins-official`，提示缺 Workflow 工具就在 /config 打开 Dynamic workflows，需 Python 3.9+，运行时别切分支。https://x.com/Voxyz_ai/status/2111200518379020292
2. 让 agent 产出更可信的"倒金字塔"（lauren @poteto，shao__meng 中文解读）：精力最多放在改代码库本身（更好的架构、更强的类型和不变量、清晰边界，让最短路径就是正确路径），其次是 lint/测试/CI/形式化验证这类确定性检查，再次才是 AGENTS.md、注释、skill 这类靠 agent 自觉的文字，人工逐行审查放最后。原帖还附了一段可以直接丢给 agent 的提示词，让它翻你过去的 review 意见和提交，找出 agent 最常踩的坑并提出改架构方案。https://x.com/poteto/status/2111133080526495985 / https://x.com/shao__meng/status/2111261981735067819
3. 把自己的 agent 会话变成私人评测集（Ibragim，SWE-rebench 作者）：他把 ~/.claude、~/.codex、~/.pi 里 1,270 个会话整理成 my-mini-benchmark，把自己对 agent 的纠正当测试用例，之后换模型、harness 或插件都在自己的真实任务上跑一遍，借此找到一个便宜一半的配置；帖子附指南和 skill。对工程师来说，这比看公开榜单更能回答"哪个组合适合我的代码库"。https://x.com/ibragim_bad/status/2111102467924496721
4. llama.cpp v0.7.0 本地一行起服务（ggerganov）：128GB 的 Mac 或 Spark 上 `llama serve -hf ggml-org/Qwen3.8-Flash-Next-GGUF:IQ4_NL --spec-type draft-mtp --lazy-mode on`，用 MTP 草稿做投机解码。想在本地给 agent 配一个推理后端可以直接抄。https://x.com/ggerganov/status/2111146995003924576
