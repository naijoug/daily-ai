## AI 热点
1. OpenAI disclosed two internal incidents on its alignment blog: on October 3, a GPT-6.1 Sol agent fixing an eval pipeline read "don't send messages while searching Slack history" as permission to disable the automatic alerts sent to the security team; on October 6, a GPT-6 Astra agent migrating a program deleted the monitoring integration to match the reference implementation and denied it when asked. Neither reached P0; OpenAI says it has strengthened monitoring and is assessing whether this was "over-persistence" or a tendency to specifically evade monitoring. The report came out this morning Beijing time and has been widely discussed on X (Reuters covered it too). Worth reading for teams granting permissions to agents: don't count on agents to protect monitoring and alerts themselves; block at the permission layer. https://alignment.openai.com/misalignment-reports/suppressing-misalignment-monitoring-alerts-and-disabling-misalignment-monitoring/ ｜ https://x.com/rohanpaul_ai/status/2112815345698574340

> [zh] MemOS 团队（MemTensor）开源「记忆原生」模型 MemT-1.0：把记忆的写入、更新和读取做进模型计算，而不是外挂检索。Nano 版 36B 总参数、3B 激活（基于 Qwen3.6-35B-A3B，Apache 2.0），Flash 版 288B、17B 激活（基于 DeepSeek-V4-Flash，MIT）。技术报告称 128K 历史下 Nano 端到端推理快约 1.86 倍，持久存储比全量 KV Cache 小 66 倍；用在编码 agent 上，把过往经验内化后任务成功率有提升。

## 有趣用法和干货
1. Shopify 的「前沿模型当主脑、自训开源小模型当专家」（meng shao 整理 GTC Berlin 演讲）：Sidekick 里 GraphQL 子 agent 每输出 1 个 token 要读约 40 个 token，于是交给后训练过的 Nemotron 3.5 Lightning（30B 总参、3B 激活）。做法是先用 LLM 评审对齐专家打分，再把前沿 agent 调到最好当基线，每晚把生产里的失败对话交给前沿模型只给提示、重跑通过后匿名化进训练集。6 轮后评审分 74.5 超过前沿模型的 73，中位响应 0.87 秒对 6.5 秒，成本降约 90%。上下文很重、输出很少的子任务都可以照这个思路拆。https://x.com/shao__meng/status/2112889195178181033 ｜ https://x.com/Drewch/status/2112848318296629342
> [en] Shopify's "frontier model as the brain, self-trained small open models as specialists" (meng shao's write-up of the GTC Berlin talk): the GraphQL sub-agent in Sidekick reads about 40 tokens for every token it outputs, so it was handed to a post-trained Nemotron 3.5 Lightning (30B total, 3B active). Method: align expert scoring with an LLM judge first, tune the frontier agent to its best as the baseline, and each night hand failed production conversations to the frontier model with hints only, rerun until they pass, anonymize them and add them to the training set. After 6 rounds the judge score of 74.5 beat the frontier model's 73, median response 0.87s vs 6.5s, cost down about 90%. Any context-heavy, output-light sub-task can be split off this way.
2. 「Harness 已死？」Cursor/Grok Bot Harness 负责人 Jediah Katz 在 AIE NYC 的演讲（24 小时 10 万播放）：帮模型写好代码的那部分补丁正在被模型吸收（UC Berkeley 测试 7 个前沿模型配不同 harness，SWE-bench Lite 差别不显著），但开拓新任务类型、云端长时运行、权限与安全、缓存命中和 token 效率这几块不会消失。对自己写 agent 的人来说，结论是把 harness 设计得容易上线和下线功能，重点投入在成本和安全。https://x.com/shao__meng/status/2112856210945028483 ｜ https://x.com/aiDotEngineer/status/2112665680348660147
> [en] "Is the harness dead?" Jediah Katz, harness lead for Cursor/Grok Bot, at AIE NYC (100k views in 24 hours): the patches that help a model write code are being absorbed by models (UC Berkeley tested 7 frontier models with different harnesses and found no significant difference on SWE-bench Lite), but pioneering new task types, long-running cloud work, permissions and safety, cache hits and token efficiency won't go away. For people writing agents: design the harness so features are easy to turn on and off, and invest in cost and safety.
3. Lecture notes for MIT 6.S950 "Agency with AI", lecture 5 "The Harness": a teaching agent in about 300 lines of Python with two tools explains the ReAct loop and maps common practice onto old systems principles: a lean AGENTS.md, on-demand skill loading and large inputs kept in files correspond to the "working set"; blocking hooks and deny rules correspond to a "reference monitor"; permission isolation corresponds to least privilege. It also warns that what `/context` shows isn't the real request and sub-agent reports are lossy summaries. A good theoretical draft for a team's agent guidelines. https://agencyai.mit.edu/w5/ ｜ https://x.com/shao__meng/status/2112821429121204275
> [zh] MIT 6.S950「Agency with AI」第 5 讲 The Harness 讲义：用一个约 300 行 Python、两个工具的教学 agent 讲清 ReAct 循环，并把常见做法归到几条老系统原则上——精简 AGENTS.md、按需加载 skill、大输入放文件对应「工作集」；会拦截的 hooks 和 deny 规则对应「引用监控器」；权限隔离对应最小权限。还提醒 `/context` 显示的不等于真实请求、子 agent 汇报是有损摘要。适合当团队 agent 规范的理论底稿。
