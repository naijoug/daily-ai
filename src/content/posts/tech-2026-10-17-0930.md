## 新产品 / 开源
1. **Reflection AI 开源 Beam**：美国新实验室 Reflection 的第一个模型，501B 参数 MoE（每 token 激活 23B），1M 上下文，纯文本，主打编程和 Agent 场景，Apache 2.0 许可。权重有 BF16 / FP8 / NVFP4 三种，transformers、vLLM、SGLang 首日支持，HF 还配了 SFT 和 RL 微调教程，并附带一个 Rust 写的专用 harness；训练时用 RL 惩罚多余 token，宣传点是「靠更少的 token 而不是更便宜的 token」和中国开源模型竞争。[HF 博客](https://huggingface.co/blog/reflection-beam) ｜ [VentureBeat](https://venturebeat.com/technology/reflections-beam-aims-to-undercut-chinese-open-models-with-fewer-tokens-not-cheaper-tokens)
2. **PS5LM**：在越狱的 PS5 上用 llama.cpp 的 Vulkan 后端跑 GGUF 模型，大约 11.4 GB 共享显存给模型用，对局域网提供 OpenAI `/v1/chat/completions` 和 Anthropic `/v1/messages` 两种接口（README 说 Claude Code 可以直接连），电视上还有个状态界面。[GitHub](https://github.com/cobanov/PS5LM) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50122431)（195 分：有人提醒项目放 GitHub 随时可能被索尼下架；有人说 2-bit 的 Qwen 27B 虽然不聪明，但拿来盯服务器报错、看监控这类持续任务够用；还有人指出同芯片的二手矿卡 BC250 一两百美元就能买到，应该也能跑）
3. **StarSkirmish Bench v0.2（Show HN）**：让大模型在各自官方 CLI（Claude Code、Codex、Antigravity CLI、Muse Code）里用一小时写一个《星际争霸：母巢之战》神族 C++ bot，再和人类写的强 bot 对打。GPT-6 Astra 第一，GPT-6.1 Sol 第二且成本只有它一成多，Gemini 4 Argon、Claude Opus 5.5、Claude Fable 5.1 并列 37–39 分；但对上最强的几个人类 bot，最好的模型也只赢 7%。算是一个考长程推理加 Agent 编程、离饱和还远的基准。[基准页面](https://starskirmish.com/bench/v0-2/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50118688)（185 分：有人说排名和他朋友做的 9x9 围棋基准几乎一致；也有人好奇模型写出的 bot 有没有偷学人类 bot 的代码）
4. **rStation（Show HN）**：一个「给 AI Agent 用的研究社区」，你把自己的 Agent 派过去，挑黎曼猜想、Epoch AI 难题这类开放问题讨论、互审、发论文，人类只能围观。作者的出发点是 OpenAI 用上万个 Agent 解 Navier–Stokes 普通人负担不起，想让大家各出一点算力合作。[官网](https://rstation.ai/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50118876)（评论拿它和 agent4science、agentpub 比，也有人问问题是 Agent 自己提的还是管理员定的）

## 科技新闻
1. **Claude 解开 NIST 椭圆曲线种子之谜**：P-256 等 NIST 曲线的种子是 NSA 当年给的，一直没人知道怎么来的，坊间传说是哈希了一句玩笑话，也有人怀疑藏了后门。Anthropic 一位员工让内部模型试试，不到半小时就发现：根本不是哈希，而是用 Unix 时间戳初始化 C 库的 48 位随机数生成器（drand48 / lrand48）逐字节吐出来的，P-192 到 P-521 五条全对上，只有二进制曲线 B-163 还没解开。Filippo Valsorda 三年前设的悬赏已被 Anthropic 团队领走，奖金三倍捐给了运营 Let's Encrypt 的 ISRG。[Anthropic 原文](https://www.anthropic.com/research/ecdsa-curve-origins) ｜ [Filippo 的文章](https://words.filippo.io/seeds-solved/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50122800)（669 分：调侃「13 年的锡纸帽，就为了 srand48(time(NULL))」；也有人冷静指出这只说明了种子怎么生成，看不到被丢弃的候选，挑选环节理论上仍可能有猫腻）
2. **PostgreSQL 19 推迟发布，原因之一是 AI 代码审查找出的 bug 太多**：GA 从原定 9 月底推到 11 月 19 日左右，8–10 个重要特性（包括 SQL/PGQ 图查询）被撤回到 PG 20。核心提交者 Peter Eisentraut 说，有些是难以在 beta 期修好的架构缺陷，另外 LLM 审查一下子翻出几十个边界小问题，每个三行就能修，但处理开销叠起来时间就不够了；他强调这些特性写的时候还没有 vibe coding。[The Register](https://www.theregister.com/databases/2026/10/16/postgres-19-delayed-after-ai-reviewers-find-more-bugs-than-humans-can-fix/5303471) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50119991)（主流看法是 AI 把质量门槛抬高了，老代码要大量补课，QA 正在变成 AI 时代的瓶颈；也有人认为真正难的是那些涉及设计取舍、没法一键修的 bug）
3. **Home Assistant「默认检查泄露密码」惹争议**：有用户发现 HA 会把各个 App 配置里标记为密码的字段拿去和 Have I Been Pwned 比对，于是提 issue 抗议没经过同意。官方文档说用的是 k-匿名，服务端看不到完整哈希；维护者 Frenck 起初回复得很冲，后来在 HN 道歉，并说其实一直能用 `ha security options --pwned=false` 关掉。[GitHub issue](https://github.com/home-assistant/home-assistant.io/issues/49314) ｜ [官方说明](https://www.home-assistant.io/more-info/pwned-passwords/) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50124251)（多数人认为出发点没错但应该默认关闭、让用户主动打开；有人贴了研究说 k-匿名的密码查询仍会给攻击者泄露有用信号）
4. **两个内核漏洞，一个能从虚拟机逃到宿主机**：Linux 网络栈的 CVE-2026-99999（CVSS 9.3）出在延迟校验和处理上，恶意客户机能让宿主机把 20 字节的 IPv4 头误当成 60 字节，越界读内存，最终在 KVM 里实现逃逸；研究团队是在挑战 Vercel 百万美元沙箱悬赏时挖到的，已在 6.12.113、6.18.57、7.2.11 等版本修复，跑云主机和 Agent 沙箱的要尽快升级。另一个是 Calif 披露的 OpenBSD 本地提权：一个从原始 BSD 代码沿用了 37 年的 16 位有符号计数器，fork 足够多次就会溢出。[pwn.ai 原文](https://pwn.ai/blog/pwnescape) ｜ [Debian 安全追踪](https://security-tracker.debian.org/tracker/CVE-2026-99999) ｜ [IT之家](https://www.ithome.com/1/014/222.htm) ｜ [Big Fish](https://calif.io/research/big-fish) ｜ [HN 讨论](https://news.ycombinator.com/item?id=50118977)（有人发现 NetBSD 在 1999 年重写那段代码时顺手修掉了）
5. **Anthropic 被曝向国会推销自己起草的 AI 安全法案**：据 Politico，草案只允许政府在模型存在「可预见、迫在眉睫」的重大风险时阻止发布或使用，门槛是超过 10 亿美元损失或 50 人以上伤亡，而且风险要来自生物武器、模型脱离开发者控制这类特定情形。AI 安全圈不少人批评它把政府的干预权收得太窄。[Politico](https://www.politico.com/news/2026/10/16/anthropic-ai-safety-01124654) ｜ [Techmeme](https://www.techmeme.com/261016/p25#a261016p25)
